# Продажа и передача клиента: рабочая памятка

[Учебная глава](../chapters/18-sales.md) · [Каноническая воронка](../../commercial/SALES_FUNNEL.md)

1. Записать допустимый источник контакта, компанию, потребность, ответственного и следующее действие.
2. Квалифицировать: критичная функция, текущий инженер, реальный restore, требуемое окно, бюджет, полномочия.
3. Провести обследование требований; технический доступ/сканирование только по письменному разрешению.
4. Рассчитать периметр, время, расходы/резерв и проверить мощность. Gold — атрибут пакета, не стадия сделки и не автоматическое 24/7.
5. КП: факты/неизвестное, состав, цена/НДС, запуск, отдельные расходы, исключения и приёмка.
6. Договор/оплата → передача инженеру подписанного периметра, контактов, ограничений/рисков и всех обещаний. Секреты через vault, не карточку.
7. Запуск после доказательств → отчёт → фактические часы/маржа → решение продления/изменения.

Стадии: New → Qualified → Discovery → Proposal → Contract → Won; Lost/Nurture с причиной/датой возврата. Переход — проверяемый результат, не выполненный звонок. Скидки — только по текущему прайсу и расчёту маржи, не ручное обещание.

Учебная практика: один играет клиента с требованием ночной поддержки, другой выясняет ограничения и формирует следующий шаг. Разбор и [видео](../VIDEO_GUIDE.md#маркетинг-и-управление) не заменяют проверку staffing владельцем.
