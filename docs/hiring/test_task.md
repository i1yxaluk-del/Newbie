# Тест-задание · MSP Junior

**Бюджет времени:** 3 часа максимум. Если не укладываешься — пришли
что успел + что бы доделал.

**Среда:** Ubuntu 22.04 VM (можно в VirtualBox / WSL / Yandex Cloud
trial / Hetzner за 3€).

---

## Часть 1 · bash (1 час)

Напиши скрипт `disk_report.sh`, который:

1. Принимает аргумент `--threshold=<%>` (по умолчанию `80`).
2. Находит все mountpoints, где заполненность ≥ threshold.
3. Для каждого печатает: mountpoint, %, top-3 директории по размеру.
4. Возвращает exit code:
   - `0` — все ниже threshold
   - `1` — хоть один выше threshold
   - `2` — ошибка выполнения

Критерии:
- `set -euo pipefail`.
- Работает на Ubuntu 22.04 без установки доп. пакетов.
- Читаемый output.

---

## Часть 2 · Ansible (1 час)

Напиши playbook `install_restic.yml`, который:

1. Устанавливает `restic` на target host (Debian/Ubuntu).
2. Создаёт `/etc/restic/env` (шаблон с заглушками `XXX`).
3. Включает systemd-timer `restic-backup.timer` (раз в сутки в 02:30).
4. Idempotent: повторный запуск не ломается и показывает `changed=0`.

Не нужно: настоящие S3-credentials, реальные backup'ы.

---

## Часть 3 · Troubleshooting write-up (1 час)

Мы дадим лог (приложен отдельно: `incident_log.txt`) — там симптомы
инцидента «клиент не может залогиниться в корп-портал». Напиши
**написанный на русском разбор** (500-800 слов):

1. **Что произошло** (в одном предложении).
2. **Что проверял бы первым** и почему.
3. **Наиболее вероятная root-cause гипотеза.**
4. **Что сделал бы для фикса** (пошагово).
5. **Что бы сделал для предотвращения** (monitoring / alert / runbook).

Критерии:
- Логика важнее «знаю-все-ответы».
- Чем короче, тем лучше — 500 слов плюс-минус.
- Не google-ответ — собственный разбор.
