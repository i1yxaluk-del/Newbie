# Compliance & Соответствие требованиям РФ

> Карта соответствия MSPShield законодательству и отраслевым требованиям.
> Актуально: 2026 год.

## 1. 152-ФЗ «О персональных данных»

### Что обрабатываем

| Тип данных | Источник | Кто оператор |
|---|---|---|
| Контакты клиента (имя, email, телефон) | Форма заявки | MSPShield (ИП) |
| Метрики серверов | Prometheus | Клиент |
| Логи сервисов (Silver+) | Loki | Клиент |
| События безопасности (Gold) | Wazuh | Клиент |

### Наш статус

- **По заявкам с лендинга:** MSPShield — оператор ПДн (контактные данные для коммуникаций).
- **По инфраструктуре клиента:** MSPShield — обработчик по поручению (клиент — оператор).

### Документы

1. **Согласие на обработку ПДн** (форма при отправке заявки) — в backend сохраняется вместе с записью.
2. **Договор-поручение на обработку ПДн** (приложение к основному договору) — для клиентов Silver/Gold.
3. **Уведомление в Роскомнадзор** о начале обработки — подаётся ИП до приёма первых данных.
4. **Политика конфиденциальности** публикуется на `/docs/privacy.html`.

### Технические меры

- TLS 1.2+ для всех HTTP-эндпоинтов (Let's Encrypt или Yandex Certificate Manager).
- AES-256 шифрование бэкапов на стороне клиента (restic) до отправки в S3.
- WireGuard (ChaCha20-Poly1305) для всего межплощадочного трафика.
- MongoDB за файрволом, доступ только с backend-сервера.
- Журналирование всех admin-действий через `/api/leads/*/status`.

## 3. Отраслевые требования

### Медицина (частные клиники)

| Требование | Источник | Как закрываем |
|---|---|---|
| Защита МИС по 4 классу | Приказ ФСТЭК №21 | Wazuh SIEM + KES + Bastion + журналы |
| Учёт действий с ПДн пациентов | 152-ФЗ | Loki + Wazuh file integrity monitoring |
| Резервное копирование МИС | ФЗ «Об охране здоровья» | restic ежедневно + ежемесячная проверка restore |
| Проверки Росздравнадзора | Постановление №152 | Пакет документов по 152-ФЗ + журналы |

### Финансы / бухгалтерия

| Требование | Источник | Как закрываем |
|---|---|---|
| Целостность бухгалтерских данных | 402-ФЗ | Бэкапы + checksum + Git-хранение конфигов |
| Защита от неавторизованного доступа | ЦБ-стандарты | MFA на Bastion, WireGuard, журналирование |
| Хранение логов ≥ 5 лет | 402-ФЗ, ФНС | Loki + архивация в Yandex S3 Cold |

## 4. Что даём клиенту «на проверку»

В договор включено приложение **«Пакет документов для проверяющих»**:

1. Договор оказания услуг + SLA.
2. Договор-поручение на обработку ПДн.
3. Акт о принятых мерах защиты ПДн.
4. Модель угроз (по шаблону ФСТЭК).
5. Журнал доступа к ресурсам клиента (экспорт из Loki/Wazuh).
6. Ежеквартальный отчёт о защищённости (для Gold).

**Важно:** мы НЕ подменяем собой DPO (Data Protection Officer) клиента. Мы — технический подрядчик.
DPO остаётся у клиента либо привлекается отдельным договором.

## 5. Юридическая упаковка самого MSPShield

- **ИП на УСН 6%** (до 250 млн ₽/год — с запасом на рост) или **ООО на УСН 15%** (если есть команда).
- **ОКВЭД:** 62.02, 62.09, 63.11, 63.11.1 (IT, хостинг, обработка данных).
- **Уведомление в Роскомнадзор** — до приёма первых ПДн.
- **Договор с ограничением ответственности** (не более 3-х среднемесячных платежей клиента).
- **Страхование проф.ответственности** (с 5-го клиента) — от 15k ₽/год в Ингосстрах / Согласие.
