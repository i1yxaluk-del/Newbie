# Yandex Cloud: где находится сервер

Yandex Cloud сдаёт в аренду вычислительные ресурсы. Вместо покупки физического сервера мы создаём виртуальную машину, подключаем диск и сеть, а затем запускаем MSPShield.

## Основные понятия

**Каталог** — папка для ресурсов одного проекта. **Виртуальная машина** — компьютер внутри облака: у него есть процессор, память, диск и сетевой адаптер. **Зона доступности** — площадка размещения. **Диск** хранит систему и данные. Остановка машины не удаляет диск.

**Облачная сеть** соединяет ресурсы. **Подсеть** задаёт диапазон внутренних адресов в одной зоне. **Публичный IP-адрес** нужен для доступа из интернета. Для рабочего домена адрес фиксируют, иначе он может измениться после остановки машины.

**Группа безопасности** — облачный сетевой фильтр. Она разрешает только нужные подключения. Второй фильтр, `ufw`, работает внутри Linux. Разрешённый порт ещё не доказывает, что программа его слушает.

**Сервисная учётная запись** — технический пользователь программы. Ей дают минимальные права. Ключ владельца нельзя складывать в `.env`.

## Что нужно проекту

Для пилота достаточно VM, постоянного адреса, сети, подсети, группы безопасности и объектного хранилища для резервных копий. Каждый ресурс получает назначение, ответственного и срок удаления.

```text
Домен → публичный адрес → группа безопасности
→ Linux → ufw → Caddy → приложение
```

`cloud-init` выполняет первичную настройку Linux. Успешное создание VM не означает успешную установку пакетов. Журнал читают так:

```bash
sudo tail -n 100 /var/log/cloud-init-output.log
```

Команда только показывает последние сто строк. Она ничего не исправляет.

## Безопасная практика

Создайте отдельный учебный каталог, сеть, подсеть и небольшую Ubuntu VM. Разрешите SSH только со своего адреса, а HTTP и HTTPS — для сайта. Подключитесь, проверьте журнал и затем удалите лабораторию. После удаления VM отдельно проверьте диски, снимки и постоянные адреса: они могут продолжать стоить денег.

Публичный SSH закрывайте только после проверки AmneziaWG во второй сессии и подготовки аварийного доступа через консоль.
