# Архив первого варианта книги

`chapters_v1/` — прежние сгенерированные главы с полными копиями документов. Их цены, маршруты и команды могут быть устаревшими. Не выполнять как действующий runbook. `build_embedded_book.py` сохранён как история, не запускать.

Текущая книга: [BOOK.md](../BOOK.md). Редактируемые материалы: `book/lessons/`, перечень глав: `book/curriculum.json`; сборка: `python book/build_deep_book.py`.
