## Подготовка публикации

Цена, рабочее окно, часы, лицензии и результат услуги должны совпадать с прайсом и MSA. Не переносить старые обещания compliance/24×7 и зарплатные сравнения в новую рекламу. Проверить `python scripts/validate_business_consistency.py`; кейсы и показатели публиковать только с доказательствами и разрешением.

## Архив

Старые нумерованные маршруты, статьи, lead magnets и seed-компании перенесены в [`arhive/`](arhive/README.md). Они сохранены для истории, не являются готовыми материалами для публикации. Актуальный коммерческий источник остаётся один — `commercial/`.
