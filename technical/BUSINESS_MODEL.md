# Бизнес-модель: связь между услугами, тарифами и маржинальностью

> Документ для владельца + sales. Объясняет, где деньги и почему тарифы устроены именно так.
> Работает в паре с [`ADDONS.md`](./ADDONS.md) (каталог дополнительных услуг).

## Основной принцип

**MRR (абонплата) — стабильность. ADDON — маржа и дифференциация.**

Тарифы Bronze/Silver/Gold покрывают **постоянные** расходы и дают предсказуемый доход.
Реальная прибыльность растёт через **дополнительные услуги**, которые мы продаём
существующим клиентам (up-sell) или смежным сегментам (cross-sell).

## Матрица «услуга × тариф»

Из [`0_Common/SERVICES/README.md`](./0_Common/SERVICES/README.md) видна связь сервисов с тарифами.
Здесь — коммерческое объяснение, **почему** именно так:

| Услуга | Bronze (входит) | Silver (входит) | Gold (входит) | ADDON |
|---|:-:|:-:|:-:|:-:|
| Мониторинг uptime/CPU/RAM/диск | ✓ | ✓ | ✓ | — |
| Blackbox (сайты, порты) | ✓ | ✓ | ✓ | — |
| Restic backup ежедневно | ✓ | ✓ | ✓ | — |
| Weekly report | ✓ | ✓ | ✓ | — |
| **1С: мониторинг платформы** | ✓ | ✓ | ✓ | — |
| **1С: мониторинг платформы + БД-экспортёр** | — | ✓ | ✓ | ADDON на Bronze |
| Централизованные логи | — | ✓ | ✓ | — |
| Автоматизация (Ansible/Puppet) | — | ✓ | ✓ | — |
| AD / FreeIPA мониторинг + GPO-baseline | — | ✓ | ✓ | ADDON на Bronze |
| Wazuh SIEM | — | — | ✓ | ADDON на Silver |
| Kaspersky SC | — | — | ✓ | Отдельная лицензия |
| osTicket | — | — | ✓ | — |
| **Monthly restore drill** | — | ✓ | ✓ | — |
| **Quarterly audit** | — | — | ✓ | — |
| Мобильная 24/7 L1 линия (Gold) | — | — | ✓ | — |

### Стратегия tier-ов: почему ровно три

- **Bronze** — «защита от катастрофы». Минимум, чтобы клиент перестал паниковать «всё само» упадёт.
- **Silver** — «качество жизни» для IT-отдела клиента. Логи, автоматизация, единая управляемость.
- **Gold** — «compliance + SLA». Это не про мониторинг, это про юр.защиту от проверок и штрафов.

## Целевая структура портфеля клиентов

При 10 клиентах (устойчивая точка для 1 человека):

| Тариф | Количество | MRR |
|---|---|---|
| Bronze | 5 | 125 000 ₽ |
| Silver | 3 | 150 000 ₽ |
| Gold | 2 | 170 000 ₽ |
| **Итого MRR** | 10 | **445 000 ₽** |
| + Setup fees (1–2 новых/мес) | | +40 000 |
| + ADDON (средний 90k/мес на 10 клиентов = 9k на клиента) | | +90 000 |
| **Общая выручка/мес** | | **≈ 575 000 ₽** |

При постепенном росте до 20 клиентов — добавляется партнёр / второй инженер.

## Upsell-воронка

```
Клиент купил Bronze
        │
        ├── через 2–3 месяца: нужны логи для диагностики
        │       └─→ предложить Silver (+25k MRR)
        │
        ├── через 6 месяцев: входит в регулируемый бизнес
        │       └─→ предложить Gold (+35k MRR)
        │
        └── ежеквартально: расширение инфраструктуры
                └─→ ADDON (диск, VM, миграция)

Gold-клиент
        │
        ├── хочет аудит безопасности раз в год
        │       └─→ ADDON «аудит ФСТЭК-совместимый» (45k)
        │
        └── новый филиал
                └─→ ADDON «разворачивание второго контура» (80k)
```

## KPI владельца MSPShield

### Операционные
- **Retention rate** ≥ 90% (< 1 ушёл клиент в год при 10 клиентах)
- **NPS** ≥ 50 (опрос раз в полгода)
- **SLA compliance** ≥ 99% (дырку выше — штраф по договору и для нас repuatational)
- **Time to onboarding** Bronze ≤ 3 дня

### Финансовые
- **MRR growth** +5–8% мес-к-мес (до точки 10 клиентов)
- **Revenue per client (ARPU)** рост через upsell: +10% год-к-году
- **Margin** держим ≥ 70% после всех расходов

### Командные
- **Выгорание инженеров** — оцениваем по переработкам и health-check 1:1 раз/2 нед
- **Junior L1 → L2** за 3–6 мес (иначе проблема в менторинге)

## Запреты «роста любой ценой»

- НЕ снижаем цены ниже 25k Bronze — это разрушает экономику и отношение рынка к MSP
- НЕ берём компании < 5 человек (не окупаются операционно)
- НЕ беремся за гос. тендера без опытного юриста (риски ≫ выгода для малой компании)
- НЕ берём одновременно > 2 новых клиентов в месяц (качество страдает)
- НЕ обещаем того, чего в договоре нет («на всякий случай сделаем»)

## Что делать, если клиент жалуется на цену

1. Не двигать цену. Двигать **скоуп**.
2. Предложить Bronze вместо Silver, если он хочет «сэкономить».
3. Показать калькулятор простоя с его параметрами — «25k — это цена 1 часа простоя у вас».
4. Если давит — отказаться. Плохой клиент убивает компанию быстрее, чем отсутствие клиентов.
