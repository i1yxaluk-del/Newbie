## Четыре контура

Система — это не одна VM. Есть публичный путь заявки, эксплуатационный мониторинг, дополнительные коммуникационные сервисы и отдельная учебная лаборатория Wazuh. Их нельзя считать одинаково защищёнными и восстановимыми только потому, что конфигурации лежат в одном Git.

```text
Посетитель → DNS → Caddy/TLS → файлы React или API → MongoDB
                                             → очередь → Kaiten/почта/разрешённые каналы
Системы → сборщики → Prometheus → Alertmanager → MAX/email/Matrix → инженер
Учебные события → Wazuh manager → Filebeat → indexer → учебные панели
```

DNS связывает имя с адресом. Caddy принимает защищённое соединение и выбирает: вернуть статический файл или передать `/api` серверной части. MongoDB хранит заявку; очередь повторяет внешнюю доставку. Kaiten хранит рабочие действия людей, а не единственную копию заявки.

## Данные и зависимости

Программа может пересоздаваться, а данные должны пережить это в томе или другом постоянном хранилище. Для каждого сервиса запишите: программа/версия, настройки, секреты, данные, сеть и владелец. Потеря конфигурации MAS отличается от потери PostgreSQL или криптографических ключей Matrix: один общий архив не доказывает восстановление всех трёх.

На одной production VM объединены многие функции. Если исчезнет VM, локальный Prometheus тоже перестанет сообщать о проблеме. Резервное оповещение должно иметь независимый источник проверки. Копия секретного хранилища на той же машине не является аварийным доступом при её потере.

## Что считать текущим

Имя `deploy/yandex/` историческое: код содержит переход почтового маршрута Cloud.ru. Документ и название каталога не подтверждают провайдера работающей VM. Подтверждение — закрытая инвентаризация и датированные проверки. Исходники, GitHub и реально запущенная сборка — три разных состояния.

## Практика и результат

Нарисуйте отдельно путь заявки и путь сигнала. Зачеркните production VM и перечислите, какие функции пропадут одновременно. Маркетолог объясняет клиенту, что означает рабочее окно; владелец показывает независимый контакт и процедуру восстановления. Если независимая проверка ещё не доказана, в отчёте так и пишут.
