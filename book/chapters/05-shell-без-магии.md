# 5. Shell без магии

> **Учебная ситуация.** Однострочная команда сработала вручную, но повредила скрипт автоматизации.

## Главное

Shell сначала разбивает строку, выполняет expansion и redirection, затем запускает программу. Поэтому кавычки — часть логики, а не оформление.

`set -Eeuo pipefail` останавливает многие тихие ошибки: ненулевой exit, unset variable и ошибку внутри pipeline. Но ожидаемые ненулевые результаты нужно обрабатывать явно.

Секрет в аргументе виден в history и иногда процесс list. Передавайте его через защищённый файл, stdin или secret mechanism конкретного инструмента.

## Слова, которые встретятся дальше

### expansion

Преобразование shell до запуска программы: `$VAR`, `$(command)`, glob `*`, quotes. Ошибка expansion означает, что вызываемая программа могла вообще не увидеть ожидаемый аргумент.

### pipeline

Соединение stdout одной команды со stdin следующей. Без `pipefail` status pipeline обычно равен status последней команды.

### процесс

Запущенный экземпляр программы: address space, PID, секрет доступаs, environment и file descriptors. Service может породить несколько процессов.

## Как это работает

В строке shell сначала выполняются quotes и expansions, затем redirections, затем запускается command. В pipeline процессы стартуют параллельно. Для резервная копия-скрипта критично различать ошибку producer и успешный `tee`; `pipefail` делает ошибку producer видимой вызывающему коду.

## Пример

```bash
set -Eeuo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"
[[ -f "$ROOT/backend/.env" ]] || { echo "нет env" >&2; exit 1; }
```

### Что здесь происходит

- `set -Eeuo pipefail` — Shell options меняют обработку ошибок текущего script; они не превращают каждую логическую ошибку в ненулевой exit.
- `ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"` — Разделите строку на программу/оператор, options и operands; затем по документации установите side effect и exit semantics.
- `[[ -f "$ROOT/backend/.env" ]] || { echo "нет env" >&2; exit 1; }` — Разделите строку на программу/оператор, options и operands; затем по документации установите side effect и exit semantics.

## Практикум

1. Разберите строку вычисления ROOT по операциям.
2. Добавьте trap, который сообщает номер упавшей строки.
3. Проверьте скрипт с пробелом в имени каталога.

## Если что-то не работает

| Наблюдение | Что это означает | Следующая проверка |
|---|---|---|
| Pipeline зелёный при ошибке первой команды | нет `pipefail`. |
| Пустая переменная стала путём `/` | нет `-u` и проверки значения. |
