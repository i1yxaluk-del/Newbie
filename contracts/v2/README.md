# Договоры МСП Облако — версия 2 (Word, протекция Исполнителя)

> Папка содержит **готовые шаблоны договоров в формате `.docx`** для оказания
> услуг по сопровождению IT-инфраструктуры (тарифы Bronze / Silver / Gold).
> Шаблоны построены с **приоритетом защиты Исполнителя** и подготовлены под
> сценарий «сначала самозанятый (НПД), потом ИП на УСН 6 %».
>
> **Это шаблоны, а не готовое юридическое заключение.** Перед подписанием с
> реальным клиентом обязательно отдайте на ревью практикующему юристу в РФ.
> Подробнее — в `LEGAL_NOTES.md`.

---

## 2. Как пересобрать .docx из шаблонов

Папка `build/` уже содержит готовые файлы. Если нужно изменить текст шаблона
(тарифы, цены, формулировки), правьте Python-файлы и пересобирайте.

```bash
cd contracts/v2
python3 build_all.py
```

Результат — обновлённые `.docx` в `build/`.

**Требуется один пакет Python:**

```bash
pip install python-docx
```

(Уже установлен в окружении проекта.)

## 3. Как использовать с клиентом

1. **Откройте** нужный `.docx` в Microsoft Word / LibreOffice Writer.
2. **Заполните жёлтые плейсхолдеры** — всё, что выделено жёлтым в шаблонах:
   - ФИО, ИНН, паспортные данные Исполнителя;
   - наименование Заказчика, ОГРН, ИНН, КПП, адрес, реквизиты;
   - номер договора, дата, город;
   - выбранный Тариф и его параметры в Приложениях № 1 и № 5 мастер-договора;
   - перечень серверов / сервисов в Приложении № 3 (Периметр);
   - подписи и реквизиты в каждом приложении.
3. **Подпишите**:
   - либо распечатайте и подпишите на бумаге (с печатью Заказчика);
   - либо подпишите КЭП через ЭДО (Контур.Диадок / СБИС) — юридически
     равнозначно (ст. 6 63-ФЗ).
4. **Сохраните копии**:
   - оригинал у Исполнителя;
   - копию — Заказчику;
   - копию — в защищённой папке (бекап).
5. **Сформируйте Чек НПД** в приложении «Мой налог» по факту первого
   платежа от Заказчика (обязательно — ст. 14 422-ФЗ).

## 4. Особенности для Исполнителя — самозанятого (НПД)

- В преамбуле мастер-договора прямо указан статус НПД и 422-ФЗ.
- В п. 4.4 прямо указано: НДС не облагается (ч. 9 ст. 2 422-ФЗ).
- В п. 3.5 чек НПД признан надлежащим первичным документом.
- В п. 2.5 — антипереквалификационная оговорка (защита от переквалификации
  ГПХ в трудовой по критериям ВС РФ № 15 от 29.05.2018).
- Заказчик не должен быть бывшим работодателем Исполнителя (последние 2 года —
  п. 8 ч. 2 ст. 6 422-ФЗ).

**При переходе на ИП на УСН 6 %:**

- Заменить преамбулу Исполнителя (см. примечание в шапке мастер-договора).
- Заменить блок реквизитов в подписях каждого документа.
- Подписать Дополнительное соглашение к действующим договорам.
- Дальнейшие чеки формируются через онлайн-кассу / БСО (упрощённо — через
  оператора кассы либо квитанцию ИП). НДС всё ещё не облагается на УСН 6 %.

## 5. Что важно сделать **до** подписания

См. `LEGAL_NOTES.md`, раздел 13. Краткий чек-лист:

- [ ] Проверить статус Исполнителя в «Мой налог» (он действительно НПД).
- [ ] Получить выписку из ЕГРЮЛ / ЕГРИП Заказчика (egrul.nalog.ru).
- [ ] Проверить полномочия подписанта Заказчика (Устав / доверенность).
- [ ] Убедиться, что Исполнитель не работал у Заказчика последние 2 года.
- [ ] Согласовать Периметр обслуживания и Тариф.
- [ ] Подписать Поручение на обработку ПДн (Silver / Gold обязательно).
- [ ] Подключить ЭДО для регулярных актов.

## 6. Принципы редактирования

- **НЕ удаляйте антипереквалификационную оговорку** (п. 2.5 мастера) — это
  критическая защита для НПД.
- **НЕ удаляйте cap ответственности** (п. 8.1 мастера) — иначе риски не ограничены.
- **НЕ удаляйте регресс-условия по ПДн** (п. 10.3 мастера) — оборотные штрафы
  с 30.05.2025 — это до 15 млн ₽ для организации.
- **НЕ удаляйте срок претензий 14 дней** (п. 8.5 мастера) — это защищает от
  ретроспективных требований за давние периоды.
- **МОЖНО изменять** конкретные цены, сроки, лимиты участия — это коммерческие
  параметры, а не правовые гарантии.
- **МОЖНО изменять** место подсудности — но рекомендую оставить «по месту
  регистрации Исполнителя» (это ваше).

## 8. Чем v2 отличается от v1 (`contracts/contract_*.html`)

| Аспект | v1 (HTML) | v2 (Word) |
|---|---|---|
| Формат | HTML, печать → PDF | `.docx`, родной Word, ЭДО-совместимый |
| Юридический статус Исполнителя | смешанный (упоминается ИП) | чёткий НПД с инструкцией перехода на ИП |
| Антипереквалификационная оговорка | нет | да (п. 2.5 мастера) |
| Поручение на обработку ПДн | внешний документ, упоминание | отдельное приложение под ред. 152-ФЗ от 01.09.2025 |
| Регресс-условия по ПДн | нет | да (мастер п. 10.3, ПДн п. 9.3) |
| Срок претензий | нет | 14 дней (мастер п. 8.5) |
| Cap ответственности | 1 платёж (Bronze) / 3 платежа (Gold) | 3 платежа во всех тарифах |
| Признание чека НПД как первички | нет | да (мастер п. 3.5) |
| Согласованные каналы связи | частично | формализованы (мастер п. 13) |
| Регламент передачи материалов | базовый | отдельный документ с правом удержания |
| Расширенный форс-мажор (санкции, upstream) | нет | да (мастер п. 11.2) |
| Антипереманивание (non-solicit) | нет | да, штраф 6 платежей, 24 мес (мастер п. 6.1.10) |
| Прямое исключение оборотных штрафов 13.11 КоАП | нет | да (ПДн п. 10.1) |

Старые HTML-шаблоны (`contracts/contract_*.html`) рекомендую оставить как
архив до момента, когда v2 будет проверен на нескольких реальных подписаниях.
