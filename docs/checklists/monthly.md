# Ежемесячная проверка

- [ ] клиентский отчёт: SLA, incidents, changes, backup/restore, risks;
- [ ] выполнить выборочный restore минимум одного объекта на клиента или по утверждённой выборке;
- [ ] проверить access matrix, MFA и уволенных/сменивших роль пользователей;
- [ ] проверить retention и рост backup repository;
- [ ] проверить Postbox/MAX alert routes контролируемым событием;
- [ ] сверить фактические часы, сверхлимит и маржу;
- [ ] выставить счета и записать payment status;
- [ ] обновить runbook после повторяющихся incidents;
- [ ] провести capacity/burnout review команды.

Отчёт отправляется клиенту только после review Product/Service Manager и инженера.
