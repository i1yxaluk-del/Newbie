# Проверка готовности книги

Эти условия составлены до финальной проверки по принципу Unlazy. Книга не сливается в `main`, пока каждый пункт не подтверждён.

- [x] **G1. Старая автоматически собранная редакция удалена.**
  - Проверка: в `book/chapters/` ровно 14 глав новой последовательной редакции.
  - Подтверждение: `python book/verify_readability.py` выводит `COMPLETE BOOK OK: 14 chapters`.

- [x] **G2. Каждая глава написана обычным русским языком.**
  - Проверка: глава содержит введение понятий до их применения, практическую работу и видео либо честное объяснение отсутствия подходящего видео.
  - Подтверждение: автоматическая проверка длины и обязательного раздела видео плюс ручное чтение глав о Yandex Cloud, приложении, экономике и найме.

- [x] **G3. Порядок обучения связан.**
  - Проверка: маршрут идёт от общей схемы к Git и облаку, затем к Linux, Docker, приложению, эксплуатации, экономике, клиентам и команде.
  - Подтверждение: `BOOK.md` и `CONTINUITY.md`.

- [x] **G4. Старые повреждённые фразы не могут вернуться незаметно.**
  - Проверка: `book/verify_readability.py` запрещает известные англо-русские обломки и старые шаблонные заголовки.

- [x] **G5. Навигация не ведёт на удалённые главы.**
  - Проверка: `python scripts/validate_markdown_links.py` в CI.

Если будущая глава вводит новый термин, автор сначала объясняет его обычными словами и показывает место в MSPShield. Только после этого допускается команда или сокращение.
