# MSPShield Academy

Учебник для Owner с базовым опытом Junior-сисадмина. Материал ведёт от Linux, сети и контейнеров к самостоятельному развёртыванию MSPShield, эксплуатации, экономике MSP и продажам.

Точка входа: [BOOK.md](BOOK.md).

Текущая базовая ревизия проекта: `89249e43a4e8b2e90d562307ef244ba95288c64c`.

## Структура

- `BOOK.md` — порядок чтения и навигация;
- `chapters/` — отдельные главы;
- `GLOSSARY.md` — определения;
- `00_AUTHORING_STANDARD.md` — методика и контроль фактов.

Практические destructive-действия сначала выполняются на отдельной VM. Перед изменениями production обязателен change с проверкой и rollback.
