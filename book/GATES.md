# Unlazy: условия готовности глубокой книги

- [x] G1 — все десять пользовательских маршрутов имеют отдельную главу и канонический источник.
- [x] G2 — книга содержит технический путь от запроса и контейнера до alert, backup и migration.
- [x] G3 — книга содержит формулы, тарифную развилку, воронку, удержание, договор и offboarding.
- [x] G4 — сокращения раскрыты в словаре и объясняются в главах.
- [x] G5 — рабочие документы включены целиком с SHA-отпечатком, а не заменены кратким пересказом.
- [x] G6 — Junior-маршрут включает недели, labs и уровни допуска.
- [x] G7 — навигация и источник каждого практического утверждения проверяемы.
