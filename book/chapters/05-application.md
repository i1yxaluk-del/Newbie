## От HTTP к документу

Python выполняет серверную логику. FastAPI сопоставляет метод/путь с функцией; Pydantic проверяет структуру запроса. Асинхронная функция позволяет ждать БД/сеть, не занимая весь процесс вычислением. Но синхронный SMTP/HTTP внутри неё способен блокировать цикл: слово async не превращает все вызовы в неблокирующие.

MongoDB хранит документы заявок. `lead.id` связывает форму, очередь и карточку CRM; это не Mongo `_id`. Индекс ускоряет поиск или запрещает повтор ключа, но не исправляет неверное бизнес-условие.

## Две точки входа

`server:app` — локальный сервер, `secure_server:app` добавляет production-проверки и устойчивую доставку. Второй модуль расширяет тот же объект приложения после загрузки `.env`; это не второй независимый API. Интеграции читают переменные при импорте, поэтому порядок загрузки важен.

Явное согласие проверяется до обычной обработки. Тело HTTP читается ASGI по частям; middleware сохраняет байты и возвращает их следующему обработчику. Ошибка здесь может оставить функцию без тела запроса, хотя клиент его отправил.

## Зачем очередь

Если CRM недоступна, принятая заявка должна остаться в БД. `delivery_enqueued` отмечает постановку задания, `pending` — неподтверждённые каналы, `next_retry_at` — следующую попытку UTC. Успешный Kaiten убирается, отказ email остаётся. Один фоновый обработчик повторяет доставку с паузой.

После сбоя между внешней отправкой и записью успеха возможен дубль. Поэтому «как минимум один раз» не равно «ровно один раз». Поиск Kaiten по external_id уменьшает часть повторов, но не создаёт атомарную гарантию при параллельных запросах. Несколько worker пока не разрешены архитектурой очереди.

## Практика и результат

Нарисовать три состояния: запись заявки, задание очереди, подтверждённая карточка/письмо. Для отказа email показать, что пользователь получил, где сохраняется работа и кто повторит. Маркетолог не обещает ответ через два часа только из-за успешного HTTP формы. Чтение кода: [карта](../../docs/development/CODE_READING.md); обучение: [Python/FastAPI](../STACK_AND_LEARNING.md).
