# Ежеквартальная проверка

- [ ] clean-room DR drill с измерением RTO/RPO;
- [ ] repository integrity check и restore разных типов данных;
- [ ] review всех runbooks и deployment lessons;
- [ ] review firewall, public ports, service accounts и API keys;
- [ ] проверить договорный scope, ПДн и upcoming renewals;
- [ ] quarterly review с клиентом: risks, roadmap, add-ons;
- [ ] Junior admission matrix и access levels пересмотрены;
- [ ] unit economics и capacity сверены с фактом;
- [ ] offboarding/deletion procedures проверены tabletop-упражнением.

DR считается выполненным только при evidence из чистой среды, а не при наличии snapshot.
