# Глоссарий

## ASGI

Протокол взаимодействия Python web-server и asynchronous application. Uvicorn принимает сеть и вызывает FastAPI через ASGI.

## Bind mount

Отображение конкретного host path внутрь container; lifecycle и permissions принадлежат host.

## Capacity

Количество работы, которое команда может выполнить за период после вычета обязательных непроектных затрат и резерва.

## Container

Процесс с настроенными Linux namespaces/cgroups и filesystem из image плюс writable layer; не отдельная VM.

## Contribution

Выручка минус прямые переменные расходы, оценённый труд, transaction costs и резерв конкретной услуги.

## Idempotency

Свойство операции, при котором повтор с тем же ключом не создаёт второй бизнес-результат.

## RPO

Максимально допустимый возраст потерянных данных; фактическое значение определяется интервалом и успешностью restore.

## RTO

Время от начала восстановления до принятого работоспособного состояния; подтверждается упражнением.

## SLA reaction

Время до подтверждения и начала диагностики в согласованном окне; не время полного восстановления.

## Source of truth

Согласованное место, которому доверяют конкретный тип факта: договор, Git, vault, ticket system или telemetry.

## Volume

Docker-managed storage с lifecycle отдельно от container.

## Working example

Полностью разобранный образец решения с пояснением причин каждого шага.
