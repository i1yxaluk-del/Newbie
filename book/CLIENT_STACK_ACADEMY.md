## Как читать карту

Список на лендинге — возможные технологии согласованного периметра, не доказательство компетенции команды по всем версиям и не список уже развёрнутых продуктов. «РФ ПО» и «open source» не означают автоматическое соответствие требованиям безопасности. Реестр и сертификат проверяются для конкретного продукта/редакции/версии.

Ниже три разных статуса: **видео указано самим поставщиком**, **официальный каталог**, **конкретное видео ещё не подобрано**. Полное воспроизведение видео в этой ревизии не проверено. Приоритет — понятная теория и воспроизводимый учебный результат, затем допуск к конкретной клиентской системе.

## Сервисы клиента: что сопровождаем

| Технология | Минимальная теория и зависимости | Обучение и видео | Практика владельца / смысл для маркетолога |
|---|---|---|---|
| Веб-сайт / API | DNS → TCP → TLS → reverse proxy → приложение → БД; сертификат, журнал, внешний поставщик | [MDN: HTTP, RU](https://developer.mozilla.org/ru/docs/Web/HTTP), [видеобаза сети](VIDEO_GUIDE.md#linux-и-сеть); отдельный проверенный курс эксплуатации веб-сайтов не подобран | На стенде отличить 502 от DNS/TLS и проверить полезный запрос. Для клиента — доступность согласованной функции, не просто ping |
| 1С:Предприятие | Платформа ≠ конфигурация; файловая база ≠ сервер/кластер + СУБД; лицензии, пользователи, регламентные задания | [Официальные видео 1С](https://v8.1c.ru/metod/video/), [подборка «Администрирование»](https://v8.1c.ru/metod/video/tag-administrirovanie/). Каталог подтверждён; конкретный базовый курс server admin ещё не отобран | Нарисовать клиент→сервер 1С→БД и сценарий восстановления учебной базы. Не обещать доработку конфигурации как сопровождение инфраструктуры |
| Active Directory | Домен, DNS, время/Kerberos, контроллеры/репликация, пользователи/группы/GPO | [Microsoft Learn: AD DS](https://learn.microsoft.com/ru-ru/windows-server/identity/ad-ds/), [Microsoft Learn Shows](https://learn.microsoft.com/en-us/shows/) — каталог, выбирать AD DS/Windows Server; конкретное русское видео не проверено | В изолированном стенде объяснить DNS-зависимость и права группы. Создание домена не даёт права перестраивать действующий AD клиента |
| Почта | SMTP отправляет, IMAP читает; очереди/ящики, MX/SPF/DKIM/DMARC, репутация | [Глава почты](chapters/08-mail.md), [документация Stalwart](https://stalw.art/docs/); подходящего проверенного русского видео по нашему direct MX/Postbox нет | Проследить одно тестовое письмо и отказ. «SMTP принял» не означает «получатель прочитал» |
| DNS | Авторитетный сервер и resolver, записи A/AAAA/CNAME/MX/TXT/SRV, TTL/кэш, зона/регистратор | [Cloudflare: DNS, RU](https://www.cloudflare.com/ru-ru/learning/dns/what-is-dns/), [видеобаза сети](VIDEO_GUIDE.md#linux-и-сеть) | Составить учебную зону без изменения production; объяснить, почему распространение/кэш мешают мгновенному откату |
| Файловый сервер | SMB/NFS, учётки/группы, права общей папки и файлов, квоты, версии/копии, шифровальщик | [Windows file server](https://learn.microsoft.com/en-us/windows-server/storage/file-server/file-server-smb-overview), [Samba docs](https://www.samba.org/samba/docs/); отдельное русское видео не подобрано | Два test-пользователя: проверить разрешённое/запрещённое чтение, восстановить один файл и права; «видна папка» не подтверждает доступ всех сотрудников |
| Windows Server | Службы, роли, Event Log, обновления, диски, персональные доступы, лицензирование | [Microsoft Learn Windows Server](https://learn.microsoft.com/ru-ru/windows-server/), [каталог видео Microsoft](https://learn.microsoft.com/en-us/shows/) | Установить роль на лицензированном стенде, прочитать журнал, проверить возврат; версии/редакции уточнять отдельно |
| Linux-серверы | Процессы/права/systemd, пакеты/репозитории, сеть/файловые системы | [Linux в книге](chapters/02-linux-network.md), [видео](VIDEO_GUIDE.md#linux-и-сеть) | Один сервис от конфигурации до прикладного запроса и восстановления |
| PostgreSQL / Postgres Pro | СУБД, роли, WAL, транзакции, блокировки, backup/restore; расширения и различия редакций Pro | [DBA1, RU: материалы и конкретные видеолекции](https://postgrespro.ru/education/courses/DBA1), [DBA2](https://postgrespro.ru/education/courses/DBA2), [DBA3](https://postgrespro.ru/education/courses/DBA3) | Учебная БД/роль, ограниченный доступ, dump/restore и проверка запроса. PostgreSQL-курс не заменяет проверку особенностей Pro Enterprise |
| MS SQL Server | Служба, логины/пользователи, журнал транзакций, модели восстановления, backup chain, лицензии | [SQL Server Learn](https://learn.microsoft.com/ru-ru/sql/sql-server/), [видео Microsoft](https://learn.microsoft.com/en-us/shows/) — конкретный вводный ролик не подтверждён | Объяснить зависимость 1С от SQL и прикладную проверку restore; не переносить команды PostgreSQL |

«+ ещё N» в старом представлении сайта — не учебная программа. Любой новый объект требует такого же паспорта: версия, назначение, зависимости, владелец, данные, лицензия, проверка и возврат.

## Минимальная последовательность до клиентского допуска

Общие Linux/сеть/права → одна система клиента в изолированном стенде → безопасное изменение → monitoring → backup/restore → incident-разбор → передача другому человеку. Не учить сразу все ОС и все СУБД: выбрать фактический первый периметр. Маркетолог для каждой технологии объясняет только назначение/зависимость/ценность и вопросы инженеру; самостоятельные административные команды от него не требуются.
