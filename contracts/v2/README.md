# Contracts v2 — legacy generator

Эта директория сохранена для истории и воспроизводимости старых DOCX. Для новых сделок используется `contracts/canonical/`.

`build_02_tariffs.py` обновлён до текущих цен и ограничений, но сгенерированный документ всё равно требует заполнения Периметра, DPA и проверки юристом. Остальные генераторы v2 могут содержать старые SLA-формулировки; не отправлять их клиенту автоматически.
