# Форма-чек-лист аудит-созвона (30 минут)

> **Что это.** Заполняемая форма, которую инженер заполняет **прямо во время** 30-минутного
> бесплатного аудит-созвона (Этап 3 в [`../new_lead_workflow.md`](../new_lead_workflow.md)).
> Из заполненной формы напрямую собирается клиентский [отчёт об аудите](audit_report_template.md)
> и [КП](kp_template.md).
>
> **Как пользоваться.** Скопируй этот файл под клиента (`audit_call_<компания>_<дата>.md`),
> заполняй поля `[ ... ]` по ходу разговора. После звонка перенеси находки в шаблон отчёта.
>
> **Связность (что от чего зависит):**
> - блок «Что видно снаружи» берётся из pre-audit листа Этапа 2 (recon: whois/dig/SSL/nmap/HIBP);
> - блок «BANT» питает решение Этапа 3 (идём в КП / отказ / отложить) и [`../bant_q_script.md`](../bant_q_script.md);
> - блок «Находки и риски» → раздел «Риски» отчёта;
> - блок «Рекомендация тарифа» → раздел «Рекомендация» отчёта и поля КП.
