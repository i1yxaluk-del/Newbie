# Карта связности Unlazy

Книга строится цепочкой: услуга → архитектура → разработка → инфраструктура → данные → наблюдение → восстановление → клиент → готовность → экономика → продажа → договор → команда.

Каждая глава обязана отвечать на четыре вопроса: что читатель уже знает; какой новый механизм появляется; где он реализован в репозитории; какое действие подтверждает понимание. Если исходный документ изменился, встроенный отпечаток перестаёт совпадать и учебник нужно пересобрать.
