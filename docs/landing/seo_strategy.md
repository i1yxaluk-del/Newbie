> Цель: к M12 получать 30+ органических визитов/день + 2–4 лида/мес через
> Яндекс. Ключевой приём — длиннохвостые запросы под «боль», не «услугу».

## 1. Целевые кластеры ключевых слов

### Кластер A · «Что делать, когда...»
- «сисадмин уволился что делать»
- «вирус зашифровал бухгалтерию что делать»
- «потеряли доступ к серверу 1с»
- «сотрудник скачал базу данных»
- «забыл пароль администратора домена»
- «как проверить бэкапы 1с»

**Конкуренция:** низкая. **Intent:** максимально горячий.

### Кластер B · «Сколько стоит / что выбрать»
- «сколько стоит сисадмин на аутсорсе»
- «аутсорс ит в москве цены»
- «managed it service цена»
- «сравнение msp провайдеров рф»
- «outsource it vs штатный админ»

**Конкуренция:** средняя. **Intent:** commercial, evaluation stage.

### Кластер C · «Как сделать»
- «мониторинг сервера prometheus grafana настроить»
- «бэкап postgres автоматический linux»
- «active directory чистка»
- «152 фз что нужно»
- «astra linux миграция с windows»

**Конкуренция:** средняя-высокая. **Intent:** informational; через
«мы помогаем» → лид.

### Кластер D · «Compliance»
- «152-фз категории что требуется»
- «фстэк аттестация процесс»
- «реестр минцифры импортозамещение»
- «siem для небольшой компании»

**Конкуренция:** высокая (отраслевые сайты). **Intent:** бизнес-лица
ищут эксперта.

## 3. Технические SEO-требования

### 3.1. Meta & structured data
- ✅ Title ≤ 60 символов, уникальные на каждую страницу.
- ✅ Description ≤ 160 символов.
- ✅ H1 один на страницу, совпадает с Title (по смыслу).
- ✅ JSON-LD LocalBusiness (уже в index.html).
- ✅ JSON-LD FAQPage для FAQ-секции.
- ⚠ Добавить JSON-LD Article для каждой статьи блога (сделать в ШАГ-4).

### 3.2. Скорость
- ✅ Lighthouse mobile ≥ 85 (Performance).
- ✅ LCP < 2.5 сек (в Москве).
- ⚠ Сжатие изображений WebP.
- ⚠ Preload ключевых шрифтов (DM Sans, Cormorant Garamond).

### 3.3. Индексация
- ✅ robots.txt разрешает всё, кроме /admin/.
- ✅ sitemap.xml с датами обновления.
- ✅ Canonical тег на главной.
- ⚠ Яндекс.Вебмастер и Google Search Console — подтверждение владения, отправка sitemap.

### 3.4. URL-структура
```
/                       — главная
/docs/privacy.html      — политика ПД
/docs/offer.html        — оферта
/docs/sla.html          — SLA
/blog/                  — список статей (planned M2)
/blog/<slug>/           — статья (slug на латинице, транслит, без кириллицы)
/cases/<slug>/          — кейс клиента (planned M4)
```

## 6. Яндекс.Метрика — ключевые события

Настраиваем как цели:

| Событие | Вес | Тип |
|---|---:|---|
| Посещение /docs/privacy.html | 0.1 | engagement |
| Посещение /docs/sla.html | 0.3 | evaluating |
| Клик по #audit (CTA scroll) | 0.5 | intent |
| Заполнена 1 строка формы | 0.7 | hot intent |
| **Форма отправлена** | **1.0** | **conversion** |
| Скролл до 75% главной | 0.2 | engagement |
| Время на странице > 3 мин | 0.3 | engagement |

Карты кликов + скроллов → корректируем дизайн raz в месяц.
