# Как Junior читать код, скрипты и конфигурации проекта

Подробный [разбор переменных и конфигурационных связей](CONFIGURATION_GUIDE.md).

## Не требуем комментарий к каждой очевидной строке

Пояснение `x = x + 1 — увеличить x на один` ничего не добавляет. Нужны ответы: **почему это действие существует, кто передаёт данные, что изменится, какой отказ возможен и как проверить результат**. Имя переменной объясняет форму, комментарий — назначение и границу. Простую строку ученик разбирает по синтаксису языка; скрытое бизнес-правило обязано быть описано.

## Паспорт исполняемого файла

В заголовке или ближайшем README должны быть: назначение, место запуска, входы/переменные окружения, обязательные зависимости, права, изменяемые файлы/службы, ожидаемый результат, стоп-условие и возврат. Если скрипт выполняется сразу при импорте, это нужно указать: читать такой файл через `import` для ознакомления нельзя.

У функции: что получает/возвращает, побочные эффекты, различие «нет данных» и «ошибка», повторный вызов. У группы переменных: единицы/часовой пояс, источник значения, когда оно читается, допустимый диапазон/пустое значение, секретность. Не повторять одинаковый контракт в каждой короткой функции: ссылка на общий раздел предпочтительнее.

## Порядок чтения по задачам

### Заявка с сайта

`frontend/src/components/sections/CTAForm.jsx` → `backend/server.py:create_lead` → `backend/secure_server.py` → `backend/integrations/*` → Mongo/CRM.

- Браузер проверяет поля для удобства; API повторно проверяет данные. Браузеру нельзя доверить решение о согласии/праве администратора.
- `server.py` загружает `.env` раньше модулей интеграций: они читают окружение при импорте. Правка env без пересоздания процесса не меняет уже прочитанное значение.
- Production использует `secure_server:app`. Он расширяет тот же `server.app`, добавляет явное согласие и меняет функцию доставки на очередь.
- `lead.id` связывает запись, задание очереди и карточку Kaiten. `delivery_enqueued` — отметка постановки, не доставки. `pending` — ещё не подтверждённые каналы. `next_retry_at` — ближайшая попытка UTC.
- Успех HTTP формы означает сохранение заявки, а не успешную отправку во все каналы. Повтор после сбоя возможен; exactly-once здесь нет. Один worker нужен из-за единственного владельца отправки.

Упражнение: нарисовать состояние заявки после отказа email при успешном Kaiten. Найти, какая функция вернёт False, какой канал останется в `pending`, кто и когда повторит.

### Содержимое landing и аналитика

`frontend/src/pages/Landing.jsx` выбирает секции, `useContent.js` читает встроенный `landing.ru.json` и местный черновик браузера. Массивы заменяются, объекты сливаются; это не проверка схемы JSON. Сброс кэша не равен перерисовке React. Редактор не публикует файл на сервер.

`REACT_APP_*` фиксируются при сборке CRA. `reachGoal()` ничего не отправит без `window.ym`; событие «форма отправлена» не равно сделке. В параметры аналитики не передаются имя/телефон/секреты.

### Оповещения monitoring

`prometheus.yml` задаёт источники и правила → Alertmanager группирует/направляет → `services/max_alerter/webhook.py`/`sender.py` либо Matrix alerter → канал связи.

MAX userbot использует сохранённую личную сессию, backend MAX Bot API — токен бота: это разные права. Проверка `/health` в Matrix alerter подтверждает настройки, не реальную доставку. Один успешный адресат не доказывает получение всеми комнатами. Синхронные HTTP/SMTP в асинхронном обработчике требуют отдельного анализа задержки; docstring не устраняет ограничение.

### Резервная копия и календарь

`migration/restic-backup.sh` → подготовленные dump/архивы → restic → метрики textfile → Prometheus → `scripts/backup_calendar.py` → Grafana.

`trap` пытается вернуть остановленные службы при выходе; `|| true` в возврате не доказывает, что они реально поднялись. Успешная копия, проверка чтения файла и восстановление приложения — три уровня проверки. Календарь сопоставляет статус с временем **задания**, а не каждым моментом наблюдения: иначе вчерашняя копия выглядела бы сегодняшней.

### Wazuh

`prepare.py` создаёт новый каталог/секреты/настройки, `start.py` меняет sysctl, генерирует сертификаты и запускает Compose. Генератор событий меняет только `training/`. `verify.py` проверяет доступность/счётчик, не полноценный экзамен. Скрипты перевода меняют локальный dashboard; это не официальный языковой пакет. [Курс и разобранные ситуации](../training/wazuh/README.md).

### Matrix invite и MSC4108

`deploy/matrix-invite/app.py` объединяет маршруты, HTML и операции MAS/Synapse; `msc4108.py` реализует обмен при привязке устройства. Это сложная зона: ссылки выбора homeserver, браузерная OIDC-сессия и авторизация приложения не равны друг другу. Криптографические ключи/контексты и переходы состояний нельзя менять по догадке. Junior читает схему с наставником; перед изменением нужны тест протокола и проверка ошибки/повторного запроса. Текущих английских комментариев недостаточно для самостоятельного сопровождения всего протокола.

## Как читать конфигурационные языки

| Формат | На что смотреть | Частая ошибка |
|---|---|---|
| YAML/Compose | Отступы, services, volumes, networks, ports, env_file, depends_on | Порт контейнера не равен публичному порту; `depends_on` не всегда ожидает готовность приложения |
| Ansible YAML/Jinja | hosts, vars, when, become, register, notify; источник `{{ variable }}` | Путать фильтр задач с перечнем узлов; относить lookup к удалённому окружению |
| systemd | User, ExecStart, EnvironmentFile, After, WantedBy, timer | `After` задаёт порядок, а не здоровье; включённый timer не доказывает backup |
| JSON dashboard | datasource UID, expr, transformations, field mappings | JSON не поддерживает комментарии: назначение хранить в description и README |
| XML Wazuh | localfile, ruleset, if_sid, field, rule ID | Синтаксически верное правило может не соответствовать ни одной реальной строке |
| Bash | set, quoting, pipelines, redirection, trap, sudo | Считать `bash -n` пробным выполнением; терять код ошибки в pipe/`|| true` |
| PowerShell | param, `$env:`, Test-Path, try/finally, внешние коды выхода | Путать строку команды и безопасные аргументы; забыть закрыть TcpClient |
| Dockerfile | WORKDIR, COPY, RUN, USER, CMD | Путь COPY зависит от build context, не расположения Dockerfile |

Перед выполнением ученик заполняет: место запуска → входы → изменения → проверка → возврат. Если хотя бы одно неизвестно — остановка и разбор с наставником.
