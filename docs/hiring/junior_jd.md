# Junior MSP Engineer — job description

**Кто ищем:** человек, который в ближайшие 6 месяцев сможет закрывать
P2/P3 инциденты и плановые работы у клиентов MSPShield. К концу 12-й
недели — полноценный engineer on call в будни.

## Что будешь делать

- Разбор P2/P3 тикетов в Kaiten (первые 3 мес — по runbook'ам, далее —
  самостоятельно).
- Плановые работы: патчи, бэкап-проверки, SSL-ротация.
- Онбординг новых клиентов — подготовка инфры, развёртывание агентов.
- Участие в weekly-sync с клиентами (слушаешь → через 2 мес ведёшь часть
  встречи → через 6 мес ведёшь самостоятельно по крепким клиентам).

## Что НЕ будешь делать в первые 6 мес

- P1 инциденты один (всегда в паре с senior).
- Ночные дежурства соло.
- Прямой контакт с новыми лидами и коммерческие обсуждения.

## Требования (hard must-have)

- Linux на среднем уровне (systemd, networking, permissions, базовый bash).
- Понимание TCP/IP, DNS, SSH.
- Базовые SQL-запросы.
- Git (commit, branch, push; merge-конфликты не обязательны, научим).
- Английский — чтение документации без переводчика.

## Требования (nice-to-have)

- Опыт с AD / GPO.
- Ansible / Terraform на уровне «читал и запускал».
- 1С как user / admin.
- Опыт с WireGuard или другим VPN.
- Grafana / Prometheus на уровне «смотрел dashboard».

## Условия

- Удалённо, график 09–18 МСК (Пн–Пт).
- ₽ 70–90k gross/мес первые 3 мес · ₽ 90–120k после перевода в senior-II
  на месяц 7.
- Официальное оформление по ГПХ (ИП/самозанятый), либо в штат после
  регистрации ООО.
- Оплата курсов по Linux/Ansible/AD — 50% (до ₽20k/квартал).
- Компенсация VPN-подписки для личного использования.

## Анти-требования (не подходит, если…)

- Ждёт готовый, прописанный заранее план «задач на день».
- Не готов брать ответственность за чужие сервера.
- Отрицательный EQ: не умеет писать клиенту спокойно при P1.
- Нужен hand-holding на каждый шаг в первые 2 недели (норма для MSP:
  50% времени в первые 2 недели ты в паре).

## Как откликнуться

- Короткое сообщение в Telegram: `@mspshield_hr`.
- Формат: «меня зовут X, живу в Y, опыт Z лет, сильная сторона A,
  слабая B, почему хочу — C. Доступна ли ссылка на портфолио/GitHub:
  да/нет».
- **Не присылай резюме** пока. Если совпадём по сообщению — дам
  25-минутный screening-звонок.
