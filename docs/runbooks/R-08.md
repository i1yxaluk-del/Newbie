# R-08 · VPN/WireGuard tunnel down

**Severity:** P2
**Tier:** all
**Time budget:** 30 мин до восстановления
**Requires:** root на bastion + клиентском gateway

---

## 1. Триггер

- Alert: `wireguard_latest_handshake_seconds > 300` (больше 5 мин без пакета).
- Alert: peer endpoint unreachable.
- Клиент сообщает: «Не могу подключиться к офису через VPN».

---

## 2. Диагностика

```bash
# На bastion
wg show
wg show <interface> latest-handshakes
ip route
systemctl status wg-quick@<interface>

# На клиентском gateway (если есть)
wg show
systemctl status wg-quick@<interface>
```

---

## 3. Действия

### 3.1. Peer не coming up

- [ ] Проверить, что endpoint IP корректный.
- [ ] Проверить, что UDP-порт открыт в security group (обе стороны).
- [ ] Проверить, что keys не rotated без нашего ведома.
- [ ] `systemctl restart wg-quick@<interface>` на обеих сторонах.

### 3.2. Tunnel up, но трафик не идёт

- [ ] `iptables -L -n -v` — нет ли правил, блокирующих forwarding.
- [ ] `sysctl net.ipv4.ip_forward` → должно быть 1.
- [ ] AllowedIPs в конфиге правильные?
- [ ] MTU (иногда нужно `MTU = 1420` явно).

### 3.3. Множественные клиенты offline

- [ ] На bastion: перезапустить сервис WireGuard.
- [ ] Если не помогает: проверить load на bastion (CPU, RAM, conntrack).
- [ ] Network:  не поменялся ли публичный IP bastion?

---

## 4. Откат

- Если меняли конфиг — вернуть прошлую версию из git:
  ```
  cd /etc/wireguard/ && git log --oneline -5
  git checkout <prev_commit> -- <interface>.conf
  systemctl restart wg-quick@<interface>
  ```

---

## 5. Проверка

- [ ] `wg show` — handshake < 180 сек.
- [ ] `ping` через tunnel до внутренних адресов работает.
- [ ] Клиент подтверждает.
- [ ] Prometheus alert зелёный.

---

## 6. Коммуникация

- Если multiple tenants затронуты (bastion-issue) — сообщение всем.
- Если 1 клиент — только ему.

---

## 7. Post-actions

- [ ] Если bastion перегружен — либо масштабировать, либо вынести часть tenant'ов в 2-й bastion.
- [ ] Регулярная ротация ключей (раз в год) — напомнить.
- [ ] Если причина в cloud-провайдере (сеть) — зафиксировать, eskalate в support.
