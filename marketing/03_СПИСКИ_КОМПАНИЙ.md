# 03 · Списки потенциальных компаний: где взять и как квалифицировать

> Честно и по делу: я **не могу выдать готовый список реальных компаний с проверенными
> телефонами/email из песочницы** — это требует доступа к платным базам и парсингу, плюс по
> 152-ФЗ контакты надо собирать из открытых источников аккуратно. Поэтому здесь — **рабочий
> плейбук**: точные источники, фильтры, как за 1–2 дня собрать 100–300 целевых компаний руками
> или полуавтоматически, и готовый шаблон таблицы (`companies_seed.csv`) под заливку в Kaiten.

---

## 1. Источники данных о компаниях в РФ (по приоритету)

### 1.1. Геосправочники — лучший старт для локальных сегментов (клиники, бухгалтерия, недвижимость)
- **2ГИС** (2gis.ru) — рубрики + фильтр по городу/району. Есть телефон, сайт, адрес.
  Пример: «медицинские центры Казань», «бухгалтерские услуги Москва ЦАО».
- **Яндекс Карты / Яндекс Бизнес** — то же + отзывы (по отзывам видно «живые» компании).
- **Zoon, Profi.ru, Yell** — дополнительные каталоги услуг.

> Как собирать: открываете рубрику → выгружаете названия+сайты+телефоны (вручную по 20–30 в день
> на сегмент, либо парсер 2ГИС). Сразу отсекаете сетевые федеральные бренды (у них свой ИБ).

### 1.2. Реестры по выручке и юрлицам — для квалификации (есть ли бюджет)
- **Контур.Фокус**, **СБИС**, **Rusprofile** (rusprofile.ru), **За Честный Бизнес**
  (zachestnyibiznes.ru) — выручка, ОКВЭД, кол-во сотрудников, ИНН, ЛПР (директор/учредитель).
- Фильтр: ОКВЭД нужного сегмента + выручка 15–150 млн ₽ + регион. Так отсекаем «анти-портрет».

### 1.3. Реестр операторов ПДн Роскомнадзора (pd.rkn.gov.ru)
- **Золотая жила:** все, кто там зарегистрирован, **официально обрабатывают ПДн** → у них есть
  наша боль по 152-ФЗ. Можно фильтровать по региону и категории данных.
- Бонус: тех, кого там НЕТ, но кто собирает данные, — им грозит штраф за отсутствие в реестре
  (100–300 тыс ₽). Тоже повод для разговора.

### 1.4. Тендерные площадки — компании, которые УЖЕ покупают ИТ/ИБ
- **РосТендер** (rostender.info), раздел «Тендеры в области IT», zakupki.gov.ru, B2B-Center.
- Ищем закупки по ключам: «информационная безопасность», «защита персональных данных»,
  «антивирус», «межсетевой экран», «аттестация ИСПДн», «пентест».
- Кто публикует такие тендеры или участвует — **уже осознал потребность**. Тёплые лиды.

### 1.5. Маркетплейсы и e-com каталоги (для сегмента 3)
- Продавцы Ozon/Wildberries/Авито с большими оборотами, рейтинги Data Insight,
  каталоги интернет-магазинов. Парсинг сайтов с формой заказа = есть ПДн покупателей.

### 1.6. Отраслевые ассоциации, бизнес-центры, ТПП, акселераторы
- Списки членов ТПП региона, резидентов технопарков/БЦ, выпускников акселераторов (ФРИИ и др.).
- Часто публикуют участников открыто → готовые квалифицированные списки по отрасли.

## 2. Пошаговый плейбук сборки списка (2 дня, ~150–300 компаний)

```
День 1 — широкий сбор (цель: 200+ строк «грязного» списка)
 1. Выбрать 3 приоритетных сегмента (например: клиники, бухгалтерия, e-com) и 2–3 города.
 2. По каждому: 2ГИС/Яндекс Карты → выгрузить название + сайт + телефон (по 30–40 на связку).
 3. Реестр РКН → добавить компании из нужных категорий ПДн по региону.
 4. РосТендер (IT) → выписать заказчиков последних 3 мес по ключам ИБ.

День 2 — квалификация и обогащение (цель: 100–150 «чистых» лидов)
 5. Каждую компанию прогнать по Rusprofile/Контур.Фокус: выручка 15–150 млн? ОКВЭД наш?
    Не сетевой бренд? → если нет, удалить.
 6. Найти ЛПР: имя директора (Rusprofile), email/телефон (сайт, раздел «Контакты»),
    Telegram/LinkedIn-аналоги — только открытые источники.
 7. Заполнить companies_seed.csv. Проставить сегмент, тариф-гипотезу, крючок, приоритет (A/B/C).
 8. Залить A-приоритет в Kaiten (колонка «Новая») через интеграцию или вручную.
```

> ← Зачем 2 дня вручную сначала, а не сразу автоматизация: на малых объёмах ручной сбор даёт
> понимание, какие фильтры работают. Когда схема устаканится — автоматизируем парсинг (могу
> написать скрипт под 2ГИС/реестр РКН, скажите — сделаю отдельным инструментом).

## 3. Критерии «брать / не брать» (чек-лист на каждую компанию)

✅ Берём, если:
- Выручка 15–150 млн ₽/год
- Есть клиентская база / ПДн / ИТ-инфраструктура
- Не сетевой федеральный бренд, не госструктура
- Есть контакт ЛПР из открытого источника

❌ Пропускаем, если:
- Выручка < 15 млн (нет бюджета) или это ИП без сотрудников
- Нет ПДн и нет инфраструктуры (нет боли)
- Уже есть свой ИБ-отдел / это конкурент / интегратор
- Госзаказчик с обязательным 44-ФЗ (сложно для старта)

## 4. Что отдать в работу прямо сейчас

Файл **`companies_seed.csv`** заполнен **49 реальными компаниями**, спарсенными из публичных
карточек 2ГИС (название, телефон, сайт, e-mail, адрес, рубрика). Демо-строки заменены на живые
лиды. Жена/junior дорабатывает по плейбуку выше (выручка, ЛПР), дальше — заливаем в воронку Kaiten.

Столбцы: `company, segment, city, revenue_band, website, decision_maker, role, contact_channel,
contact_value, source, hook, tariff_hypo, priority, status, notes`.

### Гео-приоритет (важно)
В первую очередь работаем по **Москве и Московской области** (в CSV они идут первыми,
`priority = A`), затем — самые релевантные компании из других городов (`priority = B`).
Сейчас в посеве: Москва — 16 карточек (8 клиники + 8 бухгалтерия/юристы, приоритет A);
Казань — 33 карточки (приоритет B, как пул для добора). При следующем парсинге расширяем
именно московский пул (клиники/медцентры, бухгалтерия, юристы, e-commerce по Москве и МО).
