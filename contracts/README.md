# Договоры

В репозитории используется **один** договорный комплект:

- [`MSP_SERVICE_AGREEMENT.md`](MSP_SERVICE_AGREEMENT.md) — редактируемый источник;
- `MSP_SERVICE_AGREEMENT.docx` — версия для согласования и подписания;
- [`build_contract_docx.py`](build_contract_docx.py) — воспроизводимая сборка DOCX.

Перед сделкой заполнить все `[ПОЛЯ]`, удалить неприменимые варианты, сверить Order Form с `commercial/PRICING.md` и передать документ практикующему юристу РФ. Шаблон не является юридическим заключением.
