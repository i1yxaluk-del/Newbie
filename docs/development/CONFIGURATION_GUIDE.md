# Связи переменных и конфигураций

## Wazuh: от подготовки до интерфейса

| Имя/параметр | Откуда приходит | Где используется и почему |
|---|---|---|
| `--host-ip` | Аргумент оператора `prepare.py` | Адрес публикации dashboard/приёма агентов. Не выбирает адрес SSH и не создаёт DNS |
| `--root`, `root` | Корневой каталог стенда | Содержит исходные конфигурации, данные, секреты и журнал версии. Не путать с `/` или root-пользователем |
| `upstream`, `project` | Клон официального tag и `single-node` | Шаблон трёх центральных компонентов, затем изменённый Compose; это не общая конфигурация всех контейнеров VM |
| `passwords` | Генератор случайных значений | Отдельные пароли оператора, службы dashboard→indexer и dashboard→API. Не выводить словарь |
| `users` | bcrypt-хэши паролей | `internal_users.yml` индексатора; хэш нужен проверке пароля, исходный пароль нужен вызывающей службе |
| `data` | Каталог на `/home` | Тома Docker через local-driver bind; перенос хранения не переносит Docker images с корневого раздела |
| `mem_limit`, `cpus` | Ограничения учебного сценария | Верхние пределы контейнера, не гарантированное резервирование всех ресурсов VM |
| `ports` | Изменяемый Compose | Левая часть — адрес/порт VM, правая — внутри контейнера. Loopback 9200/55000 не равен LAN 443/1514 |
| `main_config`, `syscheck`, `localfile` | Разобранный XML Wazuh | Выбор источника JSONL и учебного каталога FIM. Эти настройки не устанавливают агент на host |
| `manifest.json` | prepare после подготовки | Версия и commit upstream. Не доказательство работающих служб |
| `vm.max_map_count` | start.py и sysctl-файл | Лимит областей отображения памяти ядра, необходимый indexer. Не меняет размер физической памяти |
| `run_id` | Генератор одного упражнения | Связывает четыре синтетических события; новое выполнение создаёт новый ID |
| `rule.id`, `if_sid`, `field` | local_rules.xml | ID правила, зависимость от родительского правила и условие поля. Перевод описания не меняет условие |

`verify.py:request()` обращается к loopback indexer с паролем в заголовке, читает состояние кластера и число учебных записей. Его локальное исключение проверки сертификата не является рекомендацией отключить TLS-проверку в клиентском приложении. Общий счётчик не доказывает успех конкретного `run_id`.

`apply_locale.py` регистрирует каталог i18n; `apply_home_translation.py` монтирует проверенный по версии шаблон и same-origin JavaScript для жёстко заданных надписей. Последний использует `MutationObserver`, потому что React создаёт элементы после первого ответа HTML. Он не должен переводить raw event/поля ввода. После обновления образа совместимость проверяется заново; каталог может существовать, но не быть загружен — это проверяется HTTP-ответом translations и авторизованным интерфейсом.

## API и очередь

| Имя | Смысл и единицы | Отличие, которое легко пропустить |
|---|---|---|
| `MONGO_URL`, `DB_NAME` | Адрес БД и имя логической базы | Наличие переменной не доказывает доступность сервера |
| `ADMIN_TOKEN`, `JWT_SECRET` | Административный пароль и подпись сессий | Не токен доставки уведомлений; их смена требует плана действующих сессий |
| `consent` | Явное логическое согласие | Строка `"true"` не является тем же объектом Python `True` при проверке middleware |
| `lead_id` | ID сохранённой заявки | Не внутренний Mongo `_id` и не ID карточки Kaiten |
| `delivery_enqueued` | Задание очереди уже создано | Не «доставлено», не «прочитано» |
| `pending` | Список неуспешных/неотправленных каналов | Отказ email не требует снова отправлять уже подтверждённый Kaiten |
| `attempts`, `delay` | Счётчик проходов и пауза в секундах | Число проходов не обязательно равно количеству HTTP-вызовов: адаптер может повторять внутри |
| `next_retry_at` | Момент UTC | Не сравнивать со строкой времени браузера в МСК без преобразования |
| `external_id` | Связь Kaiten с lead ID | Поиск прежней записи помогает от дублей, но не даёт атомарную блокировку |

## Monitoring и backup

`Prometheus` собирает метрики, `Alertmanager` группирует/направляет сообщения, `Grafana` рисует запросы. `datasource.uid` в JSON должен совпасть с provisioning источника, иначе правильный запрос останется без данных. `expr` — запрос, `transformations` меняет форму ответа для таблицы; цвета — представление, не проверка безопасности.

`restic_backup_success`: 0 — ошибка, 1 — успех задания, 2 — выполняется. `restic_backup_timestamp_seconds` — время начала запуска. В календаре отдельно используется время наблюдения Prometheus и дата этого запуска. `msp_backup_calendar_generated_seconds` позволяет скрыть устаревшую таблицу; старый файл с зелёным значением без контроля возраста вводит в заблуждение.

`STAGING` — подготовленный комплект архивов, не конечное хранилище restic. `RESTIC_PASSWORD` шифрует репозиторий; S3 credentials разрешают операции с объектами. Потеря любого из них может сделать восстановление невозможным. В production и альтернативной Ansible-роли разные файлы env: не смешивать пути только из-за одинакового имени продукта.

## Учебный разбор любого нового параметра

Заполнить шесть полей: название → кто задаёт → когда читается → единицы/допустимые значения → кто использует → последствия неверного значения. Если параметр секретный, записывать только место хранения и процедуру получения, не само значение. Неизвестное помечать как требующее проверки, а не угадывать по имени.
