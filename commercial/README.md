## Правила

1. Bronze, Silver и Gold продаются в обычном процессе.
2. Gold — расширенный тариф: SIEM Wazuh + Kaspersky Security, DR-drill, SLA-отчёты; состав фиксируется в Order Form.
3. Monitoring 24/7 не означает круглосуточное дежурство инженера; режим реакции фиксируется в договоре.
4. Compliance, RTO/RPO и восстановление не гарантируются без scope и evidence.
5. Любой скан клиента — только после письменного разрешения.
6. Цена в КП и договоре копируется из `PRICING.md`; отклонения фиксируются в Order Form.
