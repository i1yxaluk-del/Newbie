# 🎯 HH-hunter Playbook — Sprint 3 (W5–W6)

> **Цель:** Найти компании, которые ищут сисадмина на HH.ru, и предложить им аутсорсинг IT-инфраструктуры от MSPShield.
>
> **Логика:** Компания, которая нанимает сисадмина, уже признаёт — им нужна IT-поддержка. Мы предлагаем ту же ценность, но дешевле, надёжнее и без риска ухода сотрудника.

---

## 1. Рабочий процесс поиска вакансий на HH.ru

### 🔍 Базовые фильтры

| Параметр | Значение |
|----------|----------|
| **Ключевые слова** | `сисадмин`, `системный администратор`, `IT-специалист`, `администратор серверов` |
| **Город** | Москва, СПБ, крупные регионы (по необходимости) |
| **Размер компании** | 20–100 человек |
| **Тип занятости** | Любая (включая частичную / фриланс) |
| **Дата публикации** | Не более 7 дней |
| **Зарплата** | 60–150 тыс. ₽ (сигнал о бюджете) |

### 📋 Этапы поиска

1. Зайти на [hh.ru/search/vacancy](https://hh.ru/search/vacancy)
2. Применить фильтры из таблицы выше
3. Открыть **~40–50 вакансий**, включая те, где требования завышены или размыты
4. Скопировать в CRM (Kaiten) карточку компании + описание вакансии
5. Прогнать через Quick-score (раздел 2)
6. Если score ≥ 3 — добавить в лист аутрича

## 2. Quick-score система: выявление болевых сигналов

### 🔴 Pain Signals (по 1 баллу за каждый)

| Сигнал | Почему это боль для MSP |
|--------|------------------------|
| **График 2/2, сменный, 24/7** | Компания не может найти одного человека на все часы — значит, нужна команда |
| **«Без опыта» или «обучим»** | Нет senior-а — риск инцидентов, нужна экспертиза |
| **Всё в одном лице** | Single point of failure — если уйдёт, никто не знает инфру |
| **Низкая зарплата (< 80k МСК)** | Не найдут хорошего — будут мучаться с джуном |
| **Требуют «горящие» навыки** | «Срочно», «вчера» — текущий админ ушёл, инфра без присмотра |
| **Дробный график / частичная занятость** | Не готовы платить за full-time — идеально для MSP по подписке |
| **Указано «1С + серверы + сеть + техподдержка»** | Ожидают универсала — нереально, нужна команда |

### ✅ Хорошие сигналы (не баллы, но повышают приоритет)

| Сигнал | Почему хорошо |
|--------|---------------|
| **Чёткий стек** | «AD, VMware, 1С» — понимают инфру, готовы платить |
| **Упоминают SLA / 24×7** | Осознают риски downtime |
| **Готовы к удалёнке** | Открыты к аутсорсинговой модели |
| **Компания растёт** | «Расширяем IT-отдел» — инфра растёт, нужна помощь |

**Скрининг:** если ≥ 3 баллов pain signals → высокий приоритет аутрича.  
Если 1–2 балла → средний приоритет.  
0 баллов → отложить / skip.

## 3. Email-адаптация (из email_templates.md · T1 · HH-outreach)

### Тема письма
> **Вакансия «Системный администратор» — альтернатива найму**

### Тело письма

```
{Имя}, добрый день.

Увидел вашу вакансию «Системный администратор» на HH. Ниша у вас
интересная — {отрасль}, размер {N} сотр.

Хочу поделиться альтернативным вариантом.

Наше агентство MSPShield берёт на себя управление IT-инфраструктурой
как сервис: мониторинг 24/7, бэкапы, реакция по SLA, все
необходимые compliance-штуки по 152-ФЗ. Делаем это командой, а
не одним человеком — поэтому уход любого инженера для клиента
не заметен.

По цифрам для компании вашего размера это обычно 25–50 тыс ₽/мес
(против 80–150k штатному + налоги + риск ухода).

Может быть, это не подходит — у каждой компании свои требования.
Но если вдруг интересно — давайте 20 мин Zoom, покажу конкретно,
что мы делаю, и честно скажу, есть ли смысл.

{Имя}
MSPShield
+7 ... · sales@msp-claude.online · msp-claude.online
```

### 💡 Совет
> Если вакансия содержит 3+ pain signal — в письме обязательно подсветите **решение конкретной боли**:
> - «График 2/2» → «Мы покрываем 24/7 командой, без sick leave и отпусков»
> - «Всё в одном лице» → «5 инженеров в ротации, нет single point of failure»
> - «Низкая зарплата» → «Фиксированная абонплата, дешевле джуна с налогами»

## 5. Метрики отслеживания

### 📊 Ключевые показатели

| Метрика | Формула | Цель |
|---------|---------|------|
| **Open rate** | (открыто / отправлено) × 100% | ≥ 55% |
| **Reply rate** | (ответили / отправлено) × 100% | ≥ 20% |
| **Discovery rate** | (созвоны / отправлено) × 100% | ≥ 10% |
| **Pain hit rate** | (Pain score ≥ 3 в аутриче / всего отправок) × 100% | ≥ 40% |
| **Conversion to deal** | (подписанные контракты / отправлено) × 100% | ≥ 2% |

**Где фиксировать:**
- Open rate — через трекер писем (Mixmax / HubSpot sales hub / Lemlist)
- Reply rate — вручную в Kaiten CRM (статусы: открыто, ответ получен, созвон назначен)
- Pain score — проставлять при скрининге

## 6. Follow-up воронка (D+3)

| День | Действие | Канал |
|------|----------|-------|
| **D+0** | Первое письмо (T1 · HH-outreach) | Email |
| **D+3** | Follow-up #1: «Не уверены? Давайте созвонимся на 3 минуты» | Email |
| **D+7** | Follow-up #2: «У нас есть кейс в вашей нише — показать?» | Email / LinkedIn |
| **D+14** | Финальное касание: «Закрыли вопрос? Если нет — предлагаем встречу» | Email + звонок |

### Шаблон Follow-up #1 (D+3)

```
Тема: Re: Вакансия «Системный администратор»

{Имя}, привет!

Написал пару дней назад — возможно, письмо затерялось.
Коротко по сути:

— не замена вашим планам найма
— альтернатива для сравнения ценой/качеством
— 20 мин Zoom, без обязательств

Если совсем не в тему — напишите, удалю из рассылки.

{Имя}
MSPShield
```

### Шаблон Follow-up #2 (D+7)

```
Тема: Re: Вакансия «Системный администратор»

{Имя}, на всякий случай держу вас в курсе:
у нас есть кейс в вашей нише — компания {N} сотр, {отрасль},
сэкономили X% на IT за Y месяцев.

Если всё ещё ищете — дайте знать, скину детали.

{Имя}
MSPShield
```

## 7. Интеграция с Kaiten CRM

### 📦 Карточка компании в Kaiten

**Поля карточки:**
- **Название:** {{CompanyName}} — {{City}}
- **Тип:** 📥 Входящий лид (HH-hunter)
- **Размер компании:** {{employees}}
- **Вакансия:** {{vacancy_title}}
- **Pain score:** {{score}}/6
- **Статус:**
- 🔍 Скрининг
- ✉️ Письмо отправлено
- 👀 Открыто
- 💬 Ответ получен
- 📞 Discovery назначен
- ✅ КП отправлено
- 📝 Контракт подписан
- ❌ Закрыто (отказ)
- **История касаний:** D+0, D+3, D+7, D+14

**Теги:**
- `hh-hunter`
- `pain-high` (score ≥ 3)
- `pain-medium` (score 1–2)
- `follow-up-needed`

### 🔁 Автоматизация (Zapier / Make)

1. При создании карточки в Kaiten → добавить тег `hh-hunter`
2. При смене статуса на «Письмо отправлено» → запустить таймер follow-up D+3
3. При смене статуса на «Ответ получен» → уведомление в Telegram/Slack менеджеру
