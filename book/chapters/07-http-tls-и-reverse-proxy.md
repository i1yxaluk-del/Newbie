# 7. HTTP, TLS и reverse proxy

> **Учебная ситуация.** Caddy отдаёт 503 после чистой установки.

Предыдущая глава: [глава 6](./06-ip-маршрут-tcp-порт-и-dns.md).

## Модель, которую нужно построить

HTTP request содержит method, target, headers и body; response — status, headers и body. 503 означает, что HTTP-ответ уже получен.

TLS проверяет владение private key и цепочку доверия. SNI позволяет выбрать сертификат по hostname до HTTP.

Reverse proxy принимает внешний TLS и создаёт отдельное соединение к upstream. Ошибка proxy и ошибка backend находятся на разных участках.

## Термины в рабочем смысле

### TLS

Протокол шифрования и проверки identity endpoint. Certificate связывает public key с именами; private key нельзя публиковать.

### reverse proxy

Сервис, который завершает клиентское соединение и создаёт новое к upstream. Поэтому client↔Caddy и Caddy↔backend диагностируются отдельно.

### socket

Kernel-объект endpoint. Listening TCP socket определяется address, port и protocol; firewall может блокировать путь, даже когда socket слушает.

## Что происходит внутри

Клиентский сертификат относится к hostname, а не к адресу backend. Caddy может успешно завершить TLS и вернуть собственный 503 без обращения к FastAPI. Поэтому сравнение `curl 127.0.0.1:8001` и `curl https://domain` локализует неисправность между приложением и proxy/front door.

## Разобранный пример

```caddy
{$MSP_DOMAIN} {
  handle /api/* { reverse_proxy 127.0.0.1:8001 }
  root * /var/www/landing
  file_server
}
```

### Как читать пример

- `{$MSP_DOMAIN} {` — Разделите строку на программу/оператор, options и operands; затем по документации установите side effect и exit semantics.
- `handle /api/* { reverse_proxy 127.0.0.1:8001 }` — Стрелка показывает направление зависимости; подпись на стрелке задаёт протокол или тип передачи.
- `root * /var/www/landing` — Стрелка показывает направление зависимости; подпись на стрелке задаёт протокол или тип передачи.
- `file_server` — Стрелка показывает направление зависимости; подпись на стрелке задаёт протокол или тип передачи.
- `}` — Разделите строку на программу/оператор, options и operands; затем по документации установите side effect и exit semantics.

## Если результат не совпал с ожиданием

| Наблюдение | Что это означает | Следующая проверка |
|---|---|---|
| TLS error до HTTP | Это сужает область поиска, но не доказывает единственную причину | проверять DNS/SNI/certificate. |
| 502 | Это сужает область поиска, но не доказывает единственную причину | proxy не получил корректный ответ upstream; 503 может быть явной заглушкой. |

## Самостоятельная работа

Решите изменённый вариант исходной ситуации: **Caddy отдаёт 503 после чистой установки.** Измените один существенный параметр — host, port, credential, dataset, пакет или ограничение клиента — и сначала письменно предскажите результат. Затем выполните проверку на безопасном стенде. В отчёте оставьте исходное предположение, фактическое наблюдение, причину расхождения и способ восстановления.
