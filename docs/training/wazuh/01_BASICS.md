# 1. Архитектура и базовые понятия

[← Курс](README.md) · [Далее: практика](02_LABS.md)

```text
Учебный JSONL / FIM → Wazuh manager → alerts.json → Filebeat
→ Wazuh indexer → Wazuh dashboard
Будущий тестовый endpoint → agent → manager (отдельный этап)
```

- **Agent** собирает данные конкретного endpoint. **Manager** декодирует и применяет правила; собственные события manager имеют ID `000`.
- **Decoder** превращает строку в поля. **Rule** оценивает эти поля; `rule.id` идентифицирует правило, `rule.level` — уровень сигнала, не автоматический договорный P1.
- **Indexer** хранит индексируемые события. **Dashboard** отображает их и предоставляет поиск. Сбой UI не обязательно означает потерю сбора; проверить каждое звено.
- **FIM** обнаруживает изменения файлов, но не восстанавливает их и не доказывает вредоносность изменения.
- **SCA** оценивает конфигурацию по выбранной политике. На manager-container результаты относятся к его ОС; автоматически применять исправления к Astra-host нельзя.
- **Syscollector** собирает inventory. Уязвимости определяются по inventory/feed: отсутствие находок может означать отсутствие данных.
- **Active Response** выполняет действия. На этой лаборатории блокировки выключены; Junior не включает их ради демонстрации.

## Сопоставление терминов интерфейса

| Интерфейс | Русский смысл | Что делать |
|---|---|---|
| Threat Hunting | Поиск угроз | Отфильтровать события по периоду, группе и endpoint |
| Configuration Assessment | Оценка конфигурации | Проверить policy, ОС и результат каждого check |
| File Integrity Monitoring | Контроль целостности файлов | Сверить путь, hash, время и разрешённое изменение |
| Vulnerability Detection | Обнаружение уязвимостей | Проверить inventory, feed, статус и применимость CVE |
| Critical/High/Medium/Low | Критическая/высокая/средняя/низкая важность правила | Оценить контекст и бизнес-влияние, не переписывать severity на глаз |

## Проверка понимания

1. Почему «no agents registered» верно при наличии событий? Источник — manager, а не внешний agent.
2. Почему green indexer не доказывает работающий сбор? Индексатор может быть исправен при сломанном Filebeat/logcollector.
3. Почему правило `backup_failed` не доказывает отказ backup? В этой практике оно создаётся синтетическим JSON.
4. Почему SCA Amazon Linux не является аудитом Astra? Проверяется контейнерная ОС, host не подключён как endpoint.
