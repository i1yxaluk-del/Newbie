# MSPShield Academy

Полный учебник для Owner MSPShield с исходным уровнем Junior-сисадмина. Материал ведёт от устройства Linux, сети и контейнеров до самостоятельного развёртывания, эксплуатации, миграции, расчёта экономики и ведения B2B-продаж.

## С чего начать

1. Откройте [`BOOK.md`](BOOK.md) — это основное оглавление и последовательность обучения.
2. Перед первой лабораторной прочитайте правила безопасного стенда в `BOOK.md`.
3. Для каждой темы сначала изучите главу, затем выполните команды на отдельной VM и только потом смотрите видео из [`VIDEO_GUIDE.md`](VIDEO_GUIDE.md).
4. Ведите `learning-log.md`: гипотеза, команда, фактический результат, причина ошибки, способ восстановления.
5. После технического блока выполните технический capstone; после коммерческого — бизнес-capstone.

## Как пользоваться видео

Видео — не замена главе и документации. В каталог включаются только материалы, для которых можно сформулировать:

- какую модель они объясняют;
- какой практический результат нужно получить после просмотра;
- какие части относятся к MSPShield;
- что в ролике устарело или не переносится в production.

Ссылки на поисковую выдачу YouTube запрещены: они нестабильны и могут вести к рекламному или поверхностному контенту. Если качественного видео по узкой технологии нет, в книге остаются официальная документация и локальный практикум, а не случайный ролик.

## Критерий завершения

Книга пройдена не после чтения, а когда Owner способен без готовой последовательности команд:

- развернуть проект на чистой VM;
- объяснить путь запроса, состояние и failure domains;
- восстановить backup в чистом окружении и измерить RPO/RTO;
- провести migration и rollback;
- обработать incident/change по журналу evidence;
- рассчитать contribution, capacity и минимальную цену;
- провести discovery, подготовить предложение и передать выигранного клиента в onboarding без потери scope.
