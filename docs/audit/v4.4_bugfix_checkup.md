## 1. Ошибки, найденные пользователем

### Bug #1 — «висящий 0» в калькуляторе на `.pain-grid-md > div:nth-child(2)`

**Где:** `frontend/src/components/sections/Pain.jsx`, три поля — «Ежемесячная выручка», «Рабочих дней», «Часов в рабочем дне».

**Причина:**
- State хранился как `number` (дефолты 3 000 000 / 22 / 9).
- `<input type="number" value={revenue}>` — контролируемый, всегда отображает текущее значение.
- При попытке очистить поле: `Number("") === 0`, плюс fallback `|| 0` в `onChange` → состояние становится `0` → в поле виден «висящий 0».
- При попытке дописать цифру после `0` браузер вставляет её после ведущего нуля (`03000000`), что раздражает глаз.

**Фикс (PR текущий):**
- State — строки (`"3000000"`, `"22"`, `"9"`), разрешён пустой ввод во время редактирования.
- `type="text" inputMode="numeric" pattern="[0-9]*"` — мобильная цифровая клавиатура без «висящего 0».
- `sanitizeDigits()` — режет нецифры, снимает ведущие нули.
- `onFocus={e.target.select()}` — клик в поле выделяет содержимое (один тап → сразу перезаписал).
- `onBlur` — если поле осталось пустым, восстанавливается дефолт (3 000 000 / 22 / 9).
- В `useMemo` — парсинг строка→число с безопасным fallback.

### Bug #2 — `/admin/leads`: токен `dev-admin-token-local-testing-only` не работает

**Где:** `frontend/src/pages/AdminLeads.jsx`, `backend/server.py` `require_admin()`.

**Три возможные причины** (бэкенд различает, фронт — нет):
1. **401 Unauthorized** — на сервере в `backend/.env` реальное значение `ADMIN_TOKEN` отличается от того, что пользователь вводит (например, при копировании `.env.example` токен оставили, но позже поменяли; или прод-деплой сгенерировал случайный).
2. **503 "Admin access not configured"** — `ADMIN_TOKEN` в `.env` пустой или переменная вообще не передалась контейнеру. FastAPI рано возвращает 503 без проверки.
3. **Network error** — `REACT_APP_BACKEND_URL` не заложен в build → `axios.get("undefined/api/leads")` → ошибка CORS/DNS; или nginx не проксирует `/api/` на `127.0.0.1:8001`.

**Фикс (PR текущий):**
- **Диагностика в UI:** форма логина теперь показывает точный источник проблемы (401 / 503 / network) + подсказку «что сделать». До этого любая ошибка схлопывалась в generic «Ошибка загрузки» → пользователь не понимал, что чинить.
- **Same-origin fallback:** `const BACKEND = process.env.REACT_APP_BACKEND_URL || ""; const API = BACKEND + "/api"` → если переменная не заложена в build, API бьёт в same-origin (`/api/leads`). На проде за nginx это работает по умолчанию, в dev — остаётся старое поведение через `.env`.
- **`.env.example`:** предупреждение выведено в шапку блока ADMIN_TOKEN с готовой командой `openssl rand -hex 32`.
- **Документация:** `docs/lifecycle/README.md` — заменена неверная ссылка `/api/admin/leads` → `/api/leads` (в server.py маршрут именно такой), добавлена таблица «симптом → причина → что сделать» для admin-login.
