# Договоры

Шаблоны договоров оказания услуг MSPShield по трём тарифам.

| Файл | Тариф | Что внутри |
|---|---|---|
| [`contract_bronze.html`](./contract_bronze.html) | Bronze | Договор + приложения: перечень услуг, SLA, стоимость |
| [`contract_silver.html`](./contract_silver.html) | Silver | То же + автоматизация, AD/DNS/GPO, логирование |
| [`contract_gold.html`](./contract_gold.html)   | Gold   | То же + SIEM/EDR, compliance, тикет-система |

## Как использовать

1. **Откройте HTML** в любом браузере и через «Печать → Сохранить как PDF» получите готовый
   документ для подписания.
2. **Заполните реквизиты** (жёлтые плейсхолдеры в шаблоне):
   - ФИО ИП / название ООО
   - ИНН, ОГРН(ИП)
   - Банковские реквизиты (БИК, р/с, банк)
   - Адрес для корреспонденции
   - Контактный email для уведомлений
3. **Приложение «SLA»** — отдельно зафиксируйте конкретные серверы клиента и их критичность.
4. **Приложение «Обработка ПДн»** — подписывается отдельно для Silver / Gold (требуется по 152-ФЗ).

## Что обязательно проверить юристом

- [ ] Формулировка ограничения ответственности (рекомендуем: не более 3-х месячных платежей).
- [ ] Условия расторжения (уведомление ≥ 30 дней, передача материалов).
- [ ] Порядок разрешения споров (арбитраж по месту регистрации исполнителя).
- [ ] Порядок индексации стоимости (привязка к ИПЦ или фиксированный пересмотр раз в 12 мес.).
- [ ] NDA-раздел (срок действия ≥ 3 лет после расторжения).

## Юридическая дисциплина

- Всегда подписываем ДО начала работ — даже если клиент «торопится».
- Чек-лист перед подписанием: сверка реквизитов, правильный тариф, актуальная дата.
- Для ЮЛ — ЭДО (Диадок / СБИС). Для ФЛ-ИП — скан с синей печатью или КЭП.
- Акт выполненных работ — ежемесячно, до 5-го числа следующего месяца.
