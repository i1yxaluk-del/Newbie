# Pre-onboarding checklist

> Чек перед Day-1 нового клиента. Проверять за 2 рабочих дня до старта.

---

## 1. Контракт и юридика

- [ ] Договор подписан обеими сторонами (ЭЦП или бумажно).
- [ ] NDA подписан (отдельный документ).
- [ ] Приложения к договору подписаны: тариф, SLA, перечень серверов.
- [ ] Платёжка отправлена, setup fee получен на расчётный счёт.
- [ ] Акт на setup + счёт на 1-й месяц абонплаты выставлены.
- [ ] Данные в бухучёт внесены (клиент заведён в Яндекс.360 / ЭДО).

## 2. Инфраструктура — pre-requisites

- [ ] Получен перечень серверов / VM от клиента (минимум: имя, IP, ОС, роль).
- [ ] Получен Диаграмма сети / топология (хотя бы на словах).
- [ ] Определены **критические сервисы** (что нельзя останавливать) и их SLA.
- [ ] Подтверждено **окно onboarding-работ** (вечера/выходные или будни).
- [ ] Контакт-матрица: кто отвечает за что со стороны клиента.

## 3. Доступы

- [ ] Sudo/admin-доступ на все серверы (с передачей по защищённому каналу).
- [ ] Доступ к панели cloud-провайдера (Yandex Cloud / Selectel) — read-only role.
- [ ] Доступ к DNS (где управляется).
- [ ] Доступ к registrar (для SSL-сертификатов).
- [ ] Доступ к AD (если Silver/Gold) — Domain Admin на pre-configured OU.
- [ ] Все пароли/ключи сохранены в Vaultwarden клиента, не в личных мессенджерах.
- [ ] MFA настроен на все админские учётки.

## 4. Техническая подготовка со стороны MSP

- [ ] Создан tenant в общем bastion (см. `technical/0_Common/wireguard/tenant_add.sh`).
- [ ] S3-бакет для бэкапов клиента: создан, политика retention применена.
- [ ] Мониторинг: кредентиалы для pull-режима Prometheus подготовлены.
- [ ] Telegram-alert channel для клиента создан.
- [ ] Loki labels для клиента выделены.
- [ ] Kaiten доска клиента создана (список runbook-карточек по SLA).
- [ ] Ansible inventory дополнен хостами клиента.

## 5. Процессы

- [ ] Контакт-дежурный у клиента знает номер SLA-горячей линии.
- [ ] Клиент ознакомлен с классификацией P1-P4.
- [ ] Клиент знает канал для P1 (Telegram + звонок) и для P4 (osTicket для Gold, email для Bronze/Silver).
- [ ] Weekly check-in: назначен день/время повторяющейся встречи (30 мин).
- [ ] Ежемесячный отчёт: формат согласован (PDF в Яндекс.Диск).

## 6. Документация (для клиента)

- [ ] Welcome-package подготовлен (см. `welcome_package.md`).
- [ ] SLA-документ приложен к договору (копия).
- [ ] Памятка «как вызвать поддержку» (1 страница) отправлена клиенту.
- [ ] Dashboard Grafana shared link отправлен клиенту (read-only).

## 7. Риски и митигации

- [ ] Перечень знаемых рисков зафиксирован в `risks.md` в Kaiten.
- [ ] DR-сценарии обсуждены: где бэкапы, куда восстанавливаем.
- [ ] Известно, что клиент делал раньше с бэкапами (реальная практика
      или «мы их делали, но test-restore не делали»).

---

## DoD для pre-onboarding

Все ✅ отметки проставлены. Если хоть 1 незавершён — **Day-1 не начинается**.

**Ответственный:** владелец (первые 5 клиентов), далее — Senior.
