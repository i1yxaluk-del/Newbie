# План разработки книги

## Контракт

Текущий этап — только архитектура обучения: методика, оглавление, зависимости тем и правила фактической точности. После согласования главы пишутся последовательно в `chapters/`, проходят предметную проверку, затем подключаются в `BOOK.md` обычными Markdown-ссылками.

## Дерево

1. Методика и фактическая дисциплина.
2. Оглавление и карта prerequisites.
3. Технические главы: фундамент → сборка → production → эксплуатация.
4. Бизнес-главы: стоимость → продукт → продажи → договор → управление.
5. Два сквозных capstone.
6. Сборка `BOOK.md` только после проверки всех глав.

## Правило unlazy

Для каждой будущей главы: сначала источники и acceptance checklist; затем черновик; затем экспертный проход на факты; затем практический прогон; затем редактура. Глава не считается готовой по числу слов. Готовность доказывается воспроизводимым практикумом и отсутствием необъяснённых шагов.
