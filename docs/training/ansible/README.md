## Что есть в репозитории

- [`technical/0_Common/ansible/`](../../../technical/0_Common/ansible/) — альтернативный контур с systemd/nginx, не текущая production-схема Caddy/Compose.
- [`examples/`](examples/) — новый отдельный пример для местного упражнения. Не устанавливает пакеты, не меняет SSH/firewall, не использует `sudo`.
- [`deploy/wazuh-lab/`](../../../deploy/wazuh-lab/README.md) — действующая лаборатория Wazuh готовится Python-скриптами. Ansible не управляет ею автоматически.

## Среда для занятий

Управляющий узел — отдельный Linux/WSL2 с установленным Ansible, Git и Python; непосредственно в Windows PowerShell `ansible-playbook` обычно не запускают. Для примера достаточно Linux и `ansible-core`. Версию фиксирует наставник в отчёте; до курса проверить `ansible --version`. Существующие роли требуют дополнительных коллекций `community.general`; установка Ansible сама по себе их наличие не доказывает.

Первый запуск — только местное упражнение ниже. Для удалённой VM нужны проверенный SSH-ключ узла, персональная учётная запись, разрешённые узлы и план возврата. Установленная на Astra лаборатория Wazuh не является полигоном для роли `baseline`: та меняет SSH и межсетевой экран.
