# Клиентские шаблоны продаж (sales templates)

Заполняемые документы, которые отдаются клиенту или используются по ходу сделки.
Дополняют процесс из [`../new_lead_workflow.md`](../new_lead_workflow.md) конкретными «рыбами».

## Что здесь

| Файл | Когда | Кому |
|------|-------|------|
| [`audit_call_checklist.md`](audit_call_checklist.md) | Этап 3 — во время 30-мин созвона | внутренний (инженер заполняет) |
| [`audit_report_template.md`](audit_report_template.md) / [`.html`](audit_report_template.html) | Этап 4 — после аудита | клиенту (PDF, письмо T4) |
| [`kp_template.md`](kp_template.md) / [`.html`](kp_template.html) | Этап 4 — после отчёта | клиенту (PDF, письмо T6) |

## Как они связаны (поток данных)

```
Этап 2 (recon)                Этап 3 (созвон)            Этап 4 (документы)
pre-audit лист  ──┐
                  ├──►  audit_call_checklist.md  ──►  audit_report_template (PDF) ──► письмо T4
BANT-вопросы ─────┘            (находки + BANT)   ──►  kp_template (PDF)           ──► письмо T6
                                                                                       │
                                                                                       ▼
                                                                        contracts/contract_<тариф>.html
```

- `.md` — мастер/рыба (удобно заполнять, хранить в Kaiten-карточке).
- `.html` — брендированная версия «МСП Облако» для печати в PDF. Открыть в браузере →
  Печать → «Сохранить как PDF». Стиль намеренно совпадает с `contracts/contract_*.html`,
  чтобы все клиентские документы выглядели единообразно.

## Правила

- Заполнить все `[ ... ]` / поля с пунктиром, удалить лишние блоки и инструкции.
- Без sales-пафоса — факты и цифры (см. tone-of-voice в `../email_templates.md`).
- Цифры SLA по тарифам синхронизированы с договорами — при изменении договоров обновить и тут:
  Bronze P1 ≤ 4 ч · Silver P1 ≤ 2 ч · Gold P1 ≤ 1 ч (24/7).
- Связанный маркетинговый ассет (lead magnet «Сисадмин ушёл — 48 часов») — в
  `marketing/lead_magnets/`.
