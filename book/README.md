## Как будет устроен репозиторий книги

```text
MSPShield_Academy_MD/
├── README.md
├── 00_AUTHORING_STANDARD.md
├── 00_BOOK_MAP.md
├── BOOK.md
├── glossary.md
├── labs/
├── assets/
└── chapters/
    ├── 01-system-map.md
    ├── 02-investigation.md
    └── ...
```

`BOOK.md` будет содержать введение, маршрут обучения и ссылки на главы. Мы не будем дублировать весь текст в одном гигантском файле: это усложняет review и рождает рассинхронизацию.

## Цикл разработки

1. Берётся один пакет глав из карты.
2. Проверяются актуальные repository sources и официальные внешние источники.
3. Пишется первая глава пакета с полностью разобранным worked example.
4. Команды действительно выполняются на безопасном стенде либо маркируются как непроверенные.
5. Удаляются повторения, необъяснённые термины и абстрактные рассуждения.
6. Проверяется связь с предыдущими и следующими главами.
7. Только после review пакет подключается к `BOOK.md`.
