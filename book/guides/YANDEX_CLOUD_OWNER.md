# Yandex Cloud для владельца MSPShield

Основное объяснение находится в главе [Контейнеры, VM и облако](../chapters/04-containers-cloud.md). `deploy/yandex/` — историческое имя пути; provider текущего ресурса подтверждается inventory, а не заголовком книги.

Старый файл оставлен как указатель, чтобы внешние ссылки не приводили к ошибке. Практику выполняйте по новой главе: создание учебного каталога, сети и виртуальной машины, проверка `cloud-init`, безопасный SSH и полное удаление платных ресурсов.
