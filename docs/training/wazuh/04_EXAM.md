# 4. Экзамен Junior Wazuh

[← Курс](README.md) · [Практика](02_LABS.md)

Наставник назначает стенд, время, scope и роль. Срок обучения не заменяет evidence. Успех не выдаёт доступ к production автоматически.

## Задания

- Нарисовать путь JSONL → decoder/rule → alerts → Filebeat → indexer → dashboard.
- Найти новый run_id и четыре правила, объяснить различия уровней и synthetic-смысла.
- Найти настоящее FIM-событие, назвать источник и объект контроля.
- Определить ОС SCA/inventory и объяснить, почему это не проверка Astra-host.
- Разобрать отсутствие зарегистрированных agents без ложного вывода «Wazuh сломан».
- Составить план диагностики отсутствующего события с каждой точкой проверки.
- Объяснить ограничения русификации и показать исходные технические поля без перевода.
- Подготовить клиентское уведомление: только факты, статус, следующий шаг, без вымышленного инцидента/гарантии защиты.

## Evidence

Дата, исполнитель/наставник, версия Wazuh и стенд, разрешённый scope, run_id, rule IDs, редактированный screenshot/query, expected/actual, задержка индексации, FIM-путь, ОС SCA, ограничения, ошибки/исправления, решение pass/repeat, допустимые операции и дата пересмотра.

**Pass:** все задания выполнены, без security-провала. **Repeat:** неверно установлен источник/объект, отсутствует evidence или синтетический сигнал выдан за реальный.

**Критический провал:** публикация credentials, сканирование соседней сети, включение блокировок, удаление индексов/volumes, подключение клиента без разрешения или изменение чужих сервисов. Остановить практику и провести разбор; production-допуск не выдаётся.

## После экзамена

Допустимы read-only разбор и помощь по согласованному lab-runbook. Enrollment, ruleset changes, retention, reset пользователей, sysctl и production Active Response остаются у старшего инженера до отдельного допуска. Для общей эксплуатации также пройти [Bronze exam](../BRONZE_EXAM.md).
