# 🎯 HH-hunter Playbook — Sprint 3 (W5–W6)

> **Цель:** Системный поиск, скрининг и аутрич кандидатов/компаний через HH.ru для закрытия вакансий в сегменте малого и среднего бизнеса (20–100 чел.)

---

## 1. Рабочий процесс поиска вакансий на HH.ru

### 🔍 Базовые фильтры

| Параметр | Значение |
|----------|----------|
| **Ключевые слова** | `сисадмин`, `системный администратор`, `IT-специалист` |
| **Город** | По заданию (Москва, СПБ, регионалы — по необходимости) |
| **Размер компании** | 20–100 человек |
| **Тип занятости** | Любая (включая частичную / фриланс) |
| **Дата публикации** | Не более 7 дней |

### 📋 Этапы поиска

1. Зайти на [hh.ru/search/vacancy](https://hh.ru/search/vacancy)
2. Применить фильтры из таблицы выше
3. Открыть **~40–50 вакансий**, включая те, где требования занижены или размыты
4. Скопировать в CRM (Kaiten) карточку компании + описание вакансии
5. Прогнать через Quick-score (раздел 2)
6. Если score ≥ 3 — добавить в лист аутрича

## 2. Quick-score система: выявление болевых сигналов

### 🔴 Red Flags / Pain Signals (по 1 баллу за каждый)

| Сигнал | Пример |
|--------|--------|
| Фразовый / неполный рабочий день | «График 2/2», «сменная работа», «частичная занятость» |
| Работа 24/7 / дежурства | «Доступность в нерабочее время», «реагирование на аварии» |
| «Без опыта» или «обучим» | Скорее всего, ищут джуна за копейки |
| Всё в одном лице | «Системный администратор + техподдержка + закупки» |
| Низкая зарплата (< 60k для МСК) | Вилка 30–50 тыс. руб. |
| Отсутствие команды IT | «Вы будете единственным IT-специалистом» |
| Требуют «горящие» навыки | «Срочно», «вчера», «пожар» |

### ✅ Хорошие сигналы (баллы не начисляются, но отмечаются)

| Сигнал | Пример |
|--------|--------|
| Чёткие задачи | «Поддержка 1С + AD + сеть» — понятный стек |
| Наличие бюджета | «Готовы оплачивать курсы / сертификацию» |
| Адекватная ЗП | От 90k для МСК, от 60k для регионов |
| Команда > 2 IT-шников | Указаны «коллеги в отделе IT» |

**Скрининг:** если ≥ 3 баллов pain signals → идёт в аутрич с высокой приоритетностью.  
Если 1–2 балла → средний приоритет.  
0 баллов → отложить / skip.

## 3. Email-адаптация (из email_templates.md · T1 · HH-outreach)

### Тема письма
> **Вакансия «Системный администратор» — готовы обсудить?**

### Тело письма

```
Привет, {Имя}!

Вижу, что вы ищете системного администратора в компанию {CompanyName}.
У меня есть кандидат, который:

✅ Закрывает 24/7-поддержку и аварийные дежурства
✅ Работал в одиночку в компании 50+ сотрудников
✅ Готов к частичной / сменной занятости
✅ Релевантный стек: AD, 1С, сети, Linux базово

Мы работаем по BANT-Q: бюджет утверждён, лицо, принимающее решение, — вы.
Могу скинуть контакты кандидата уже сегодня. Когда удобно созвониться на 5 минут?

С уважением,
{Ваше имя}
{Контакты}
```

### 💡 Совет
> Если вакансия содержит 3+ pain signal — в письме обязательно подсветите **решение боли** («готов к дежурствам», «работал в одиночку», «без опыта — не проблема, у нас подготовленный кандидат»).

## 5. Метрики отслеживания

### 📊 Ключевые показатели

| Метрика | Формула | Цель |
|---------|---------|------|
| **Open rate** | (открыто / отправлено) × 100% | ≥ 55% |
| **Reply rate** | (ответили / открыто) × 100% | ≥ 20% |
| **Conversion rate** | (созвоны / отправлено) × 100% | ≥ 10% |
| **Pain hit rate** | (Pain score ≥ 3 в аутриче / всего отправок) × 100% | ≥ 40% |

**Где фиксировать:**  
- Open rate — через трекер писем (Mixmax / HubSpot sales hub / Lemlist)
- Reply rate — вручную в Kaiten CRM (статусы: открыто, ответ получен, созвон назначен)
- Pain score — проставлять при скрининге

## 6. Follow-up воронка (D+3)

| День | Действие | Канал |
|------|----------|-------|
| **D+0** | Первое письмо (T1 · HH-outreach) | Email |
| **D+3** | Follow-up #1: «Не уверены? Давайте созвонимся на 3 минуты» | Email |
| **D+7** | Follow-up #2: «У нас ещё есть 2 кандидата под ваш запрос» | Email / LinkedIn |
| **D+14** | Финальное касание: «Закрыли вопрос? Если нет — предлагаем встречу» | Email + звонок |

### Шаблон Follow-up #1 (D+3)

```
Тема: Re: Вакансия «Системный администратор»

{Имя}, привет!

Написал пару дней назад — возможно, письмо затерялось.
Кандидат по-прежнему доступен и заинтересован.
Давайте созвонимся на 3 минуты в четверг или пятницу?

{Ваше имя}
```

### Шаблон Follow-up #2 (D+7)

```
Тема: Re: Вакансия «Системный администратор»

{Имя}, на всякий случай держу вас в курсе:
у нас появилось ещё 2 кандидата с опытом в вашей нише.

Если всё ещё ищете — дайте знать, скину контакты.

{Ваше имя}
```

3. При смене статуса на «Ответ получен» → уведомление в Telegram/Slack менеджеру

## Приложение: BANT-Q скрипт для звонка

> Используйте при созвоне с HR / ЛПР

| Буква | Вопрос |
|-------|--------|
| **B** (Budget) | «Бюджет на эту позицию утверждён или ещё в процессе?» |
| **A** (Authority) | «Вы принимаете финальное решение по найму?» |
| **N** (Need) | «Какая главная боль сейчас — 24/7 поддержка или нехватка рук?» |
| **T** (Timeline) | «На когда нужен сотрудник — вчера, неделя, месяц?» |
| **Q** (Qualify) | «Если я покажу кандидата с нужным стеком — готовы рассмотреть на этой неделе?» |

---

> **Спринт 3** — фокус на количестве: 30 компаний в листе, 15+ отправленных писем, 5+ созданных звонков.  
> Каждую пятницу — ревью метрик и корректировка скриптов.
