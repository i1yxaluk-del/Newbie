## 1. Методология

1. **Инвентарь.** Прогон по всему дереву `*.md` — 60+ файлов (README, runbooks, deployment guides, SOPs, training, audit, contracts, sales/onboarding/landing).
2. **Источник правды — код, а не доки.** Каждое утверждение в доках сверялось с реальным `docker-compose.yml`, `Caddyfile`, скриптами bootstrap, terraform, ansible playbooks.
3. **Git history.** `git log --oneline` за период 7 мая → 3 июня + список merged PR (#16–#52) — какие изменения попали в `main` через PR vs прямой push.
4. **CHANGELOG sanity.** Сравнение последних версий CHANGELOG с фактическими тегами / commit messages.

## 3. Найденные gaps (9 шт.)

### Critical (3)

#### C1 — CHANGELOG stale: отсутствуют v5.3 и v5.4

- **Симптом:** последняя запись в CHANGELOG — v5.2 (26 мая). Между v5.2 и сегодняшним днём (3 июня) — мониторинг-стек, Postbox :465, training wk3-4, брендинг. Ничего из этого не отражено.
- **Impact:** новый разработчик, открывший CHANGELOG, не понимает текущее состояние стека (думает что Postbox ещё на :587, что мониторинга нет).
- **Fix (закрыт в v5.4):** добавлены entries v5.3 и v5.4 со всем содержанием.

#### C2 — README stack-table указывает на deprecated файл

- **Симптом:** в таблице «Технический стек» строка «Mail (исходящий)» написано «Stalwart → Yandex Cloud Postbox (587 STARTTLS)» со ссылкой на `STALWART_RELAY_MODE.md`. Реальность: Stalwart как relay **не используется** с v4.3 (Postbox direct), :587 заменён на :465 implicit TLS в v5.3.
- **Impact:** читатель идёт в STALWART_RELAY_MODE.md и пытается развернуть устаревшую схему.
- **Fix (закрыт в v5.4):** строка обновлена на «Yandex Cloud Postbox (MSA :465, implicit TLS)» со ссылкой на `deploy/yandex/README.md`.

#### C3 — v4.1_inventory.md без disclaimer

- **Симптом:** файл `docs/audit/v4.1_inventory.md` (апрель 2026) описывает инвентарь Марафона 3.1–3.5, но ничего не говорит, что с тех пор было ~15 релизов. Кто-то открывший этот файл может принять его за актуальное состояние.
- **Impact:** дезориентация — артефакты названы существующими, ссылки кликабельны, но компоненты типа WireGuard/Stalwart описаны как «to do», хотя они давно заменены на AmneziaWG/Postbox.
- **Fix (закрыт в v5.4):** добавлен баннер «исторический snapshot — не отражает текущее состояние репо» со ссылками на CHANGELOG и v5.4-отчёт.

### Medium (4)

#### M1 — 17 коммитов без PR в `main`

- **Симптом:** 2-3 июня 2026 в `main` напрямую закоммичено ~17 правок (брендирование, training wk3-4, мониторинг-стек) — без PR, без code review.
- **Причина:** Pipedream OAuth-токен имеет scope `contents:write`, но не `refs:write` — нельзя создавать branches → нельзя открыть PR. Прямой push разрешён.
- **Impact:** теряется audit trail на уровне PR; нет диффа в UI; review не было.
- **План (v5.5):** перевыпустить токен с `refs:write` ИЛИ перейти на fine-grained PAT с правами на branches. После этого жёсткое правило «PR-only».

#### M2 — Training week 5-12 — skeleton'ы

- **Симптом:** `docs/training/week_05.md` … `week_12.md` существуют как файлы, но содержат только заголовки и краткие планы — не полностью расписаны.
- **Impact:** Junior, дойдя до 5-й недели, упрётся в пустые задания.
- **План (Этап 4, спринт 8-12):** наполнение по расписанию roadmap.

#### M3 — R-08 runbook упоминает WireGuard

- **Симптом:** `docs/runbooks/R-08.md` называется «VPN down» и в теле говорит про WireGuard. Реальный стек — AmneziaWG с v4.4 (May 2026). Заголовок обновлён до «AmneziaWG», тело — нет.
- **Impact:** инцидент-респондер по runbook'у будет пытаться рестартить `wg-quick`, а нужно `awg-quick`. Команды отличаются.
- **План (v5.5):** обновить тело R-08, все `wg` → `awg`, путь к конфигам, troubleshooting BOM/MTU.

#### M4 — STALWART_RELAY_MODE.md без deprecation-маркера

- **Симптом:** файл `deploy/yandex/STALWART_RELAY_MODE.md` существует, описывает submit-only режим Stalwart как relay. С v4.3 эта схема не используется (Postbox direct).
- **Impact:** ссылки из README ведут сюда, читатель пытается поднять Stalwart.
- **Fix (закрыт в v5.4 — Commit B):** добавлен баннер deprecated сверху файла, объяснение что Postbox direct, ссылка на актуальный README.

### Low (2)

#### L1 — Пустые директории `docs/contracts_v2/`

- **Симптом:** существует пустая (или почти пустая) папка `docs/contracts_v2/`. В CHANGELOG не упоминается. Статус неясен.
- **План (v5.5):** либо удалить (если эксперимент), либо наполнить + добавить в CHANGELOG.

#### L2 — Cosmetic-опечатки

- **Симптом:** в README/доках встречаются мелкие опечатки: «Kaizen» вместо «Kaiten», «MongoDb» вместо «MongoDB», `msps`**s**`heild.conf` (должно `mspshield.conf`), «рестрyктура» вместо «реструктура» (с латинской `y`).
- **Impact:** косметика. Поиск по репо за «Kaizen» или «mspssheild» ломается.
- **План (v5.5):** отдельный proofread-pass.
