# Как бесплатно поднять сайт в выдаче и заставить ИИ рекомендовать вас: практическое руководство

> **TL;DR:** Классического SEO уже недостаточно. В 2025–2026 году половина поисковых запросов
> проходит через AI — ChatGPT Search, Яндекс с нейро-ответами, Perplexity. Если ваш сайт
> не оптимизирован под AI-поисковики, вы теряете трафик. Ниже — пошаговая инструкция, как
> сделать так, чтобы нейросети сами рекомендовали ваш сайт. Бесплатно, без рекламы и накруток.

## Зачем вообще оптимизировать под ИИ?

Раньше всё было просто: написал статью, вставил ключевые слова, получил позицию в Яндексе.
Сейчас всё изменилось. Люди всё чаще спрашивают не поисковик, а ИИ-ассистента:

- «Какой MSP-провайдер подойдёт для малого бизнеса в Москве?»
- «Как настроить мониторинг сервера?»
- «Что делать, если сисадмин уволился?»

И ИИ отвечает — цитируя конкретные сайты. Вопрос: будет ли среди них ваш?

Эта статья — пошаговая инструкция. Каждый шаг — конкретное действие с примером кода или
настройки. Ничего платного, никаких сервисов за $99/мес. Только то, что можно сделать
руками за выходные.

## Часть 1. Классический SEO — фундамент, без которого ничего не работает

Прежде чем говорить про ИИ, убедитесь, что базовые вещи на месте. AI-поисковики всё равно
берут данные из индекса — если вас нет в Яндексе и Google, нейросеть вас не процитирует.

### 1.1. Мета-теги: title и description

Каждая страница должна иметь уникальные `<title>` и `<meta description>`.

```html
<title>Мониторинг серверов 24/7 для малого бизнеса — MSPShield</title>
<meta name="description" content="Управляемый мониторинг серверов с реакцией
по SLA от 1 часа. Prometheus + Grafana, уведомления в Telegram. От 25 000 ₽/мес." />
```

**Правила:**
- `title` — до 60 символов, главный ключ в начале
- `description` — до 160 символов, конкретика (цифры, цены, сроки)
- Без воды: «лучший сервис в России» → бесполезно; «реакция за 1 час, от 25 000 ₽» → полезно

### 1.2. Заголовки: один H1, логичная иерархия

```html
<h1>Мониторинг серверов для малого бизнеса</h1>         <!-- один на страницу -->
  <h2>Что входит в мониторинг</h2>
    <h3>Prometheus + Grafana</h3>
    <h3>Alertmanager → Telegram</h3>
  <h2>Тарифы</h2>
  <h2>Частые вопросы</h2>
```

Поисковики (и ИИ) используют иерархию заголовков, чтобы понять структуру страницы.
Если у вас 5 тегов H1 на одной странице — это хаос для краулера.

### 1.3. Скорость загрузки (Core Web Vitals)

Проверьте бесплатно: [PageSpeed Insights](https://pagespeed.web.dev/)

**Целевые показатели:**
- **LCP** (загрузка основного контента) — < 2,5 сек
- **FID / INP** (отзывчивость) — < 100 мс
- **CLS** (визуальная стабильность) — < 0,1

**Что делать:**
- Изображения → WebP (конвертировать через `cwebp` или Squoosh.app)
- Шрифты → `font-display: swap` + preload
- CSS/JS → минификация + lazy load для тяжёлого
- Если SPA (React/Vue) → серверный рендеринг (SSR) или статическая генерация

### 1.4. Мобильная версия

Google и Яндекс индексируют мобильную версию первой (mobile-first indexing). Если сайт
не адаптивен — вы теряете позиции. Проверьте через Chrome DevTools → Toggle Device Toolbar.

### 1.5. HTTPS — обязательно

Без HTTPS сайт помечается как «Не защищён». Бесплатный сертификат — Let's Encrypt
(автопродление через Certbot или Caddy).

### 1.6. Индексация: robots.txt + sitemap.xml

```
# robots.txt
User-agent: *
Allow: /
Disallow: /admin/
Sitemap: https://example.ru/sitemap.xml
```

```xml
<!-- sitemap.xml — простой пример -->
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://example.ru/</loc>
    <lastmod>2026-06-01</lastmod>
    <priority>1.0</priority>
  </url>
  <url>
    <loc>https://example.ru/blog/sysadmin-ushel/</loc>
    <lastmod>2026-05-15</lastmod>
    <priority>0.8</priority>
  </url>
</urlset>
```

Отправьте sitemap в [Яндекс.Вебмастер](https://webmaster.yandex.ru) и
[Google Search Console](https://search.google.com/search-console).

## Часть 2. Schema.org — разметка, которую понимают и поисковики, и ИИ

Schema.org — это структурированные данные в формате JSON-LD, которые вы добавляете в код
страницы. Поисковики используют их для расширенных сниппетов, а AI-модели — для извлечения
фактов.

### 2.1. Organization — кто вы

Вставьте в `<head>` главной страницы:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "MSPShield",
  "alternateName": "МСП Облако",
  "url": "https://msp-claude.online",
  "logo": "https://msp-claude.online/logo.png",
  "description": "Управляемый IT-сервис для малого и среднего бизнеса: мониторинг 24/7, бэкапы, реакция по SLA, поддержка 152-ФЗ.",
  "foundingDate": "2026",
  "areaServed": {
    "@type": "Country",
    "name": "Россия"
  },
  "contactPoint": {
    "@type": "ContactPoint",
    "telephone": "+7-XXX-XXX-XX-XX",
    "email": "sales@msp-claude.online",
    "contactType": "sales"
  },
  "sameAs": [
    "https://t.me/mspshield"
  ]
}
</script>
```

**Зачем:** ИИ-модели строят «граф знаний» — связывают название компании с её описанием,
контактами, сферой деятельности. Без этой разметки вы — просто текст на странице.

### 2.2. FAQPage — вопросы и ответы

Это самая мощная разметка для AI. Нейросети буквально забирают пары «вопрос — ответ»
и вставляют в свои ответы.

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "Сколько стоит IT-аутсорс для малого бизнеса?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Управляемый IT-сервис для компании с 1–5 серверами стоит от 25 000 ₽/мес. В пакет входит мониторинг 24/7, автоматические бэкапы, реакция на инциденты по SLA ≤ 4 часа."
      }
    },
    {
      "@type": "Question",
      "name": "Что делать, если сисадмин уволился?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Первые 48 часов критичны: заблокируйте доступы ушедшего сотрудника, проверьте бэкапы, смените пароли от критичных систем. Подробный чеклист — в нашем блоге."
      }
    }
  ]
}
</script>
```

**Совет:** добавьте на сайт блок FAQ с 10–15 реальными вопросами клиентов. Каждый вопрос
размечайте через FAQPage. Это работает и для расширенных сниппетов в Яндексе, и для AI.

### 2.3. Article — для статей блога

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "Сисадмин уволился: чеклист первых 48 часов",
  "author": {
    "@type": "Person",
    "name": "Илья Лукьянченко",
    "jobTitle": "Основатель MSPShield"
  },
  "publisher": {
    "@type": "Organization",
    "name": "MSPShield"
  },
  "datePublished": "2026-05-01",
  "dateModified": "2026-06-10",
  "description": "Пошаговый чеклист: что делать в первые 48 часов после увольнения системного администратора.",
  "mainEntityOfPage": "https://msp-claude.online/blog/sysadmin-ushel/"
}
</script>
```

**Важно:** `dateModified` — обновляйте при каждом изменении статьи. AI-модели отдают
предпочтение свежему контенту.

### 2.4. BreadcrumbList — навигация

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {"@type": "ListItem", "position": 1, "name": "Главная", "item": "https://msp-claude.online/"},
    {"@type": "ListItem", "position": 2, "name": "Блог", "item": "https://msp-claude.online/blog/"},
    {"@type": "ListItem", "position": 3, "name": "Сисадмин уволился: чеклист 48 часов"}
  ]
}
</script>
```

### 2.5. HowTo — для инструкций

Если у вас есть пошаговые гайды (а они должны быть), размечайте их:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "HowTo",
  "name": "Как настроить мониторинг сервера с Prometheus",
  "step": [
    {
      "@type": "HowToStep",
      "name": "Установка Prometheus",
      "text": "Скачайте последнюю версию с github.com/prometheus и распакуйте на сервер."
    },
    {
      "@type": "HowToStep",
      "name": "Настройка targets",
      "text": "Добавьте в prometheus.yml адреса серверов для мониторинга."
    }
  ]
}
</script>
```

## Часть 3. GEO — оптимизация под AI-поисковики (главное новшество)

GEO (Generative Engine Optimization) — это набор техник, которые помогают вашему контенту
попадать в ответы AI-поисковиков: ChatGPT Search, Perplexity, Яндекс с нейро-ответами,
Google AI Overviews.

### 3.1. Файл `/llms.txt` — визитка для нейросетей

Это новый стандарт (llmstxt.org). Файл `llms.txt` в корне сайта — как robots.txt,
но для ИИ. Он говорит нейросети: «вот мои самые важные страницы, прочитай их».

Создайте файл `https://ваш-сайт.ru/llms.txt`:

```markdown
# MSPShield

> Управляемый IT-сервис (MSP) для малого и среднего бизнеса в России.
> Мониторинг 24/7, автоматические бэкапы, реакция по SLA, поддержка 152-ФЗ.
> Три тарифа: Bronze (от 25 000 ₽/мес), Silver (50 000 ₽), Gold (85 000 ₽).

## Основные страницы

- [Главная](https://msp-claude.online/): Описание сервиса, тарифы, форма заявки
- [SLA](https://msp-claude.online/docs/sla.html): Соглашение об уровне обслуживания
- [Политика ПД](https://msp-claude.online/docs/privacy.html): Обработка персональных данных

## Блог

- [Сисадмин уволился: чеклист 48 часов](https://msp-claude.online/blog/sysadmin-ushel/): Что делать в первые 48 часов
- [Штатный админ vs MSP: калькулятор](https://msp-claude.online/blog/admin-vs-msp/): Сравнение стоимости

## Документация

- [Оферта](https://msp-claude.online/docs/offer.html): Публичная оферта
```

**Как это работает:** Когда AI-краулер заходит на ваш сайт, он первым делом ищет
`/llms.txt`. Если находит — читает именно те страницы, которые вы указали. Без этого файла
нейросеть может проиндексировать что угодно (или ничего).

**Дополнительно:** создайте `llms-full.txt` — расширенную версию с полным текстом ключевых
страниц в Markdown. Некоторые AI-модели предпочитают именно его.

### 3.2. Разрешите AI-краулерам доступ через robots.txt

По умолчанию многие сайты блокируют AI-ботов. Проверьте свой `robots.txt` и убедитесь,
что основные AI-краулеры разрешены:

```
# robots.txt — разрешаем AI-краулеры
User-agent: *
Allow: /
Disallow: /admin/

# Явно разрешаем AI-ботов (на случай если CMS добавляет блокировки)
User-agent: ChatGPT-User
Allow: /

User-agent: GPTBot
Allow: /

User-agent: PerplexityBot
Allow: /

User-agent: ClaudeBot
Allow: /

User-agent: Applebot-Extended
Allow: /

User-agent: cohere-ai
Allow: /

Sitemap: https://example.ru/sitemap.xml
```

**Внимание:** некоторые CMS (WordPress, Tilda) по умолчанию блокируют GPTBot и другие
AI-краулеры. Проверьте ваш `robots.txt` прямо сейчас.

### 3.3. Структура контента для цитирования

AI-модели «любят» контент, который легко вырезать и процитировать. Вот что работает:

**✅ Работает:**

```markdown
## Сколько стоит IT-аутсорс?

Управляемый IT-сервис для малого бизнеса (1–5 серверов) стоит от 25 000 ₽/мес.
В базовый пакет входит:

- Мониторинг 24/7 (Prometheus + Grafana)
- Автоматические бэкапы (Restic, стратегия 3-2-1)
- Реакция на критический инцидент: ≤ 4 часа (Bronze) / ≤ 2 часа (Silver) / ≤ 1 час (Gold)
- Ежемесячный отчёт о состоянии инфраструктуры

| Тариф | Серверов | Цена | Реакция P1 |
|-------|----------|------|------------|
| Bronze | 1–5 | 25 000 ₽/мес | ≤ 4 ч |
| Silver | 6–15 | 50 000 ₽/мес | ≤ 2 ч |
| Gold | 16–30 | 85 000 ₽/мес | ≤ 1 ч 24/7 |
```

**❌ Не работает:**

```
Мы предоставляем комплексные решения в области IT-инфраструктуры,
обеспечивая высокий уровень сервиса для наших клиентов по всей России.
Наши тарифы разработаны с учётом потребностей бизнеса разного масштаба.
```

**Правило:** если нейросеть не может вырезать из вашего текста готовый ответ на вопрос
пользователя за 2–3 предложения — она возьмёт ответ с другого сайта.

### 3.4. TL;DR и саммари в каждой статье

В начале каждой статьи блога добавляйте блок-резюме:

```markdown
> **Кратко:** Штатный сисадмин в Москве обходится в 150–200 тыс. ₽/мес
> (зарплата + налоги + рабочее место). MSP-пакет на те же задачи — 25–50 тыс. ₽.
> Экономия ×3–4, но подходит не всем. Ниже — калькулятор и разбор, когда что выгоднее.
```

AI-модели часто используют именно этот блок для своих ответов.

### 3.5. E-E-A-T: сигналы экспертности

Google и AI-модели оценивают **Experience, Expertise, Authoritativeness, Trustworthiness**:

- **Автор:** Укажите автора каждой статьи (имя, должность, фото). Создайте страницу «О нас»
  с биографией. Разметьте через Person в JSON-LD.
- **Факты, а не мнения:** «Мы крутые» → бесполезно. «За последний год подняли аптайм с 97.2%
  до 99.8% для 3 клиентов» → ценно (если правда).
- **Ссылки на источники:** Ссылайтесь на документацию, ГОСТы, RFC. AI считает такой контент
  более надёжным.
- **Обновление дат:** Указывайте дату публикации и последнего обновления. Устаревший контент
  теряет позиции и в поиске, и в AI.
- **Юридическая информация:** Страницы «Оферта», «Политика ПД», контактные данные, ИНН —
  всё это сигналы доверия.

## Часть 4. Контентная стратегия: что писать, чтобы ИИ вас рекомендовал

### 4.1. Пишите ответы на вопросы, а не продающие тексты

AI-поисковики отвечают на вопросы. Значит, ваш контент должен быть ответом.

**Формула:** один вопрос → один H2 → прямой ответ в первом абзаце → детали ниже.

Плохо: «Наши преимущества в IT-аутсорсинге»
Хорошо: «Сколько стоит IT-аутсорс для компании на 50 человек?»

### 4.2. Сравнительные статьи

AI обожает сравнения (это самый частый тип запросов к нейросетям):

- «Zabbix vs Prometheus: что выбрать для малого бизнеса»
- «Штатный сисадмин vs MSP: таблица расчёта»
- «Acronis vs Restic vs Veeam: бэкапы для СМБ»

Обязательно включайте таблицу сравнения — AI модели извлекают данные из таблиц лучше,
чем из текста.

### 4.3. Списки и чеклисты

- «12 вещей, которые нужно сделать, когда уволился сисадмин»
- «Чеклист 152-ФЗ для малого бизнеса: 15 пунктов»
- «7 признаков, что ваш MSP-провайдер халтурит»

Форматируйте нумерованными списками — AI буквально копирует их в свои ответы.

### 4.4. Глоссарий и определения

Создайте страницу глоссария или добавляйте определения прямо в статьи:

```markdown
**MSP (Managed Service Provider)** — компания, которая берёт на себя управление
IT-инфраструктурой клиента по подписке: мониторинг, бэкапы, безопасность, поддержка
пользователей. В отличие от разового аутсорса, MSP работает проактивно и по SLA.
```

AI-модели используют такие определения, когда пользователь спрашивает «что такое MSP».

## Часть 5. Бесплатные инструменты для проверки

### 5.1. Проверка Schema.org

- [Google Rich Results Test](https://search.google.com/test/rich-results) — проверит JSON-LD
- [Schema Markup Validator](https://validator.schema.org/) — валидация schema.org

### 5.2. Проверка SEO

- [PageSpeed Insights](https://pagespeed.web.dev/) — скорость и Core Web Vitals
- [Яндекс.Вебмастер](https://webmaster.yandex.ru) — индексация, ошибки, позиции
- [Google Search Console](https://search.google.com/search-console) — то же для Google

### 5.3. Проверка AI-оптимизации

- Откройте ваш `robots.txt` и убедитесь, что GPTBot/PerplexityBot не заблокированы
- Проверьте `https://ваш-сайт.ru/llms.txt` — файл должен отдаваться с HTTP 200
- Спросите ChatGPT / Perplexity / Яндекс: «Какие MSP-провайдеры есть в России?» —
  и проверьте, упоминаетесь ли вы

### 5.4. Мониторинг позиций

- Яндекс.Вебмастер → «Поисковые запросы» (бесплатно)
- Google Search Console → «Эффективность» (бесплатно)
- Проверка в AI: раз в неделю задавайте релевантные вопросы в ChatGPT, Perplexity
  и Яндекс с нейросетью. Скриншотьте, если вас процитировали.

## Часть 6. Чеклист внедрения (по приоритету)

Вот порядок, в котором стоит внедрять всё вышеописанное:

### Неделя 1 — Фундамент
- [ ] Проверить HTTPS (если нет — поставить Let's Encrypt)
- [ ] Проверить robots.txt — убрать блокировки AI-ботов
- [ ] Создать / обновить sitemap.xml
- [ ] Отправить sitemap в Яндекс.Вебмастер и Google Search Console
- [ ] Проверить Core Web Vitals через PageSpeed Insights

### Неделя 2 — Schema.org
- [ ] Добавить Organization JSON-LD на главную страницу
- [ ] Добавить FAQPage JSON-LD (минимум 10 вопросов)
- [ ] Добавить BreadcrumbList JSON-LD

### Неделя 3 — AI-оптимизация

## Вопросы основателю

**Q: Это точно бесплатно? Никаких платных сервисов?**
A: Да. Всё, что описано в статье, делается руками через бесплатные инструменты: Яндекс.Вебмастер,
Google Search Console, PageSpeed Insights, текстовый редактор для JSON-LD и llms.txt.

**Q: Через сколько будет результат?**
A: Schema.org и расширенные сниппеты — 1–4 недели. AI-цитирование — от 1 до 3 месяцев
(зависит от частоты переиндексации моделей). SEO-позиции — 3–6 месяцев для новых статей.

**Q: А если у меня Tilda / конструктор?**
A: JSON-LD можно добавить через блок «Вставка HTML» (есть в любом конструкторе). llms.txt
нужно залить вручную — если конструктор позволяет загружать файлы в корень сайта. Если нет —
это ограничение платформы, и для серьёзного SEO лучше перейти на собственный хостинг.

**Q: Может ли это навредить?**
A: Нет. Всё описанное — это белые методы, рекомендованные Google, Яндексом и сообществом
llmstxt.org. Никаких накруток, покупки ссылок или серых схем.
