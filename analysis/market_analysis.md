# Анализ рынка MSP в РФ · редакция 2026

> Обновлено: апрель 2026. Единственная актуальная редакция; предыдущая версия удалена при cleanup v4.1.

## 1. Что изменилось в рынке 2024 → 2026

| Тренд | Что это значит для MSP |
|---|---|
| Тотальная замена Microsoft System Center / Zabbix Enterprise на OSS | Рост спроса на внедрение Prometheus/Grafana/Wazuh |
| Миграция с VMware на OpenStack / Proxmox / ZVirt | Заказчикам нужен партнёр, который «умеет не только Windows» |
| Astra Linux, РЕД ОС, ALT — стандарт для гос. и полугос. заказчика | Знание отечественных дистрибутивов = допуск к сегменту C |
| Reconquista Kaspersky → занял доли F-Secure/ESET | Легче обосновать KES в Gold-тарифе |
| Реестр отечественного ПО — требование тендеров | Приоритет российского стека в предложении |
| ФСТЭК-проверки чаще у медицины, финансов, образования | Формируется устойчивый спрос на SIEM/EDR |
| Рост стоимости штатного IT-персонала (зарплаты +25–40% за 2 года) | MSP становится экономически выгоднее найма |

## 2. Целевая аудитория: реальный портрет 2026

### Сегмент A — «Тихая боль» (70% сделок, Bronze/Silver)

- **Кто:** владельцы бизнеса 15–80 человек, без штатного IT или с «приходящим»
- **Отрасли:** юр., бух., консалтинг, оптовая торговля, лёгкое производство
- **Типичный стек:** 1С + файловый сервер + почта + Битрикс24
- **Боль:** узнают о проблеме от сотрудников, бэкапы «примерно делаются»
- **Бюджет:** 25–50k ₽/мес при чётком обосновании ROI
- **Где ищут:** Telegram-каналы бухгалтеров, 2ГИС, HeadHunter (перехват)

### Сегмент B — «Compliance-чувствительные» (10% сделок, Gold)

- **Кто:** главбухи, ген.дира медклиник, руководители IT в финансах
- **Отрасли:** медицина (МИС), клиники, страхование, образование
- **Боль:** проверки ФСТЭК / Росздравнадзор / Роскомнадзор, штрафы по 152-ФЗ
- **Бюджет:** 85–150k ₽/мес + разовый запуск 50–100k ₽
- **Где ищут:** ассоциации медклиник, конференции, рекомендации

### Сегмент C — «IT-отдел без системности» (20% сделок, Silver)

- **Кто:** IT-директор в компании 80–300 человек
- **Отрасли:** логистика, розница, сервис, производство
- **Боль:** 2–3 айтишника тушат пожары, нет Git/Ansible/документации
- **Бюджет:** 50–100k ₽/мес
- **Где ищут:** LinkedIn/VC, через 1С-франчайзи, IT-конференции

### Кого НЕ берём

- Компании < 5 человек (экономика не складывается)
- Чистые стартапы без выручки (нечем платить)
- «Программисты-директора» (сделают сами, только ментора ищут)
- Госконтракты и 44-ФЗ-тендеры (долгий цикл, высокий порог входа)

## 3. Конкурентный ландшафт 2026

| Сегмент | Представители | Слабое место | Наш ответ |
|---|---|---|---|
| Крупные интеграторы | ЛАНИТ, КРОК, Softline, Компьюлинк | Цены от 150k, долгие циклы | Быстрее, дешевле, ближе |
| MSP-облака | ITGlobal, Servicepipe, Linx | Унифицированный сервис | Персональный подход |
| Фрилансеры / ИП | Сотни на Kwork, Avito | Нет регламентов, bus factor | SLA + документация + Git |
| «Эникейщики» | Локальные частники | Тушат пожары, нет проактива | Мониторинг 24/7 |
| Внутренний IT-отдел | Штатные | Дорого, отпуска, болезни | Экономия 40–60% |

**Реальный конкурент — инерция «нас устраивает как есть».** Задача продаж — не
победить конкурента, а изменить восприятие статус-кво.

## 6. Воронка продаж

```
Касание → Вовлечение → Квалификация → Аудит → КП → Договор → Онбординг → Удержание
  5-10%      40%            60%          70%    40%    90%       100%        95% retention
```

| Этап | Цель | Метрика |
|---|---|---|
| Касание | Привлечь внимание | CTR с объявления / упоминание в чате |
| Вовлечение | Получить контакт | Подписка, ответ в личке |
| Квалификация | 15-минутный звонок | Есть серверы, бюджет, ЛПР |
| Аудит | 30-минутный онлайн-разбор | Конкретные риски + цифры |
| КП | Персональное предложение за 24ч | Открытие письма, обратная связь |
| Договор | Подписание и 1-я оплата | Счёт оплачен в срок |
| Онбординг | 1–3 дня до работающего мониторинга | Первый weekly-отчёт ушёл |
| Удержание | Ежемесячное продление | ≥ 12 месяцев MRR на клиента |

## 7. Ключевые выводы 2026

1. **Проект жизнеспособен** при корректной юр.упаковке (ИП УСН или ООО)
2. **Первые 3 месяца** — инвестиционный период: 5–10 бесплатных аудитов
3. **8–10 клиентов** — точка финансовой устойчивости одного исполнителя
4. **Главный риск** — выгорание от совмещения продаж и техники
5. **Главный актив** — первые 3 кейса, отработанные идеально → рекомендации
6. **Автоматизация критична**: каждый не-автоматизированный процесс ограничивает масштаб
