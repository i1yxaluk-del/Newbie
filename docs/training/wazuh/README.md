# Wazuh: обучение Junior на действующем стенде

[← Программа Junior](../README.md) · [Технический runbook](../../../deploy/wazuh-lab/README.md)

Это основной учебный маршрут, а `deploy/wazuh-lab/` содержит конфигурации/скрипты. Курс описывает Wazuh **4.14.5**, развернутый на Astra Linux 1.8 в Docker, а не будущий клиентский SOC.

## Перед началом

- Лаборатория: **https://192.168.114.10**, нужна локальная сеть или разрешённый VPN-маршрут. Публичного адреса нет.
- Учётную запись и доверие учебному CA выдаёт наставник. `admin` — операторская bootstrap-учётка, не общий пароль группы. Для самостоятельного read-only доступа требуется отдельная роль; пока она не выдана — работа с наставником.
- На стенде зарегистрированных внешних агентов пока нет. События `agent.id=000` поступают от manager; это не доказательство подключения Astra/Windows endpoints.
- Локальная русификация оболочки и карточек главной страницы частичная. Данные событий и поля остаются в исходном виде; перевод интерфейса не меняет смысл правил и их severity.
- Никаких production-данных, сканирования соседних узлов, brute force или реального malware. Учебные сигналы создаются только в выделенном `training/`.

## Фактический статус на 15.10.2026

| Проверка | Что подтверждено | Чего не доказывает |
|---|---|---|
| Dashboard | Страница входа HTTP 200 | Вход каждой учётки и работа каждого раздела |
| Indexer | Cluster green | HA, backup и retention |
| JSON scenarios | 4 события в `wazuh-alerts-*`, rules 100100–100103 | Реальные атаки/подключённые клиентские agents |
| FIM | Найдено событие изменения учебного файла | Мониторинг всей Astra-host filesystem |
| SCA | Выполняется политика ОС контейнера | CIS-аудит Astra или compliance РФ |
| Vulnerability detection | Включён config | Завершённый CVE scan/успешная загрузка feed — требуется evidence |
| Русификация | Каталог i18n и локальный script доставлены | Полный официальный перевод/визуальная приёмка всех экранов |

Наставник обновляет статус после практики с датой и ссылкой на evidence. Само наличие этой таблицы не подтверждает состояние VM сегодня.
