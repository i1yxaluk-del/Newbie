# Книга владельца MSPShield

Книга объясняет проект с уровня Junior-администратора: сначала общая картина, затем GitHub, Yandex Cloud, виртуальная машина, сервисы, эксплуатация, деньги, клиенты и найм.

Начните с [`BOOK.md`](BOOK.md). Не читайте главы по номеру файла: маршрут в оглавлении специально перестроен по зависимостям знаний.

- [`NATURAL_WRITING_SKILL.md`](NATURAL_WRITING_SKILL.md) — обязательный стиль без канцелярита и необъяснённых сокращений.
- [`CONTINUITY.md`](CONTINUITY.md) — карта связности по принципу Unlazy.
- [`VIDEO_GUIDE.md`](VIDEO_GUIDE.md) — проверенные видеоматериалы.
- [`guides/`](guides/) — практические руководства.

Команды выполняются на учебной VM. Рабочая инфраструктура меняется только по актуальным runbook с планом возврата.
