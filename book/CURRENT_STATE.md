# Текущая картина и границы доказательств

[← Книга](BOOK.md)

Редакция книги сверена с репозиторием и датированными отчётами 15–16.10.2026. Сегодняшнее состояние VM нельзя вывести из даты текста: перед работой нужен текущий read-only осмотр.

| Область | Что известно | Что остаётся проверить |
|---|---|---|
| Публичный сайт | Собран/опубликован landing, проверены HTTP и API | Реальная схема ПДн и реквизиты, полный путь каждой интеграции после изменений |
| Backend | Production secure_server, очередь в Mongo, тесты отказов | Согласованный rollout всех последних исходников; горизонтальные worker не разрешены |
| Monitoring | Grafana/Prometheus/Alertmanager, календарь в Backups | Независимая от VM наблюдаемость, актуальные маршруты/сертификаты |
| Облако/почта | Путь deploy/yandex исторический, есть Cloud.ru direct MX | Фактический provider/inventory и маршрут каждого отправителя |
| Matrix/MAS/допсервисы | Отдельные deployed контуры и конфигурации | Полный прикладной DR всех БД/ключей; неподтверждённые app login пути |
| Wazuh | Astra lab 4.14.5, synthetic rules, штатные SSH/FIM, панели | Реальные клиентские agents/интеграции, роли изоляции, завершённый CVE feed/scan |
| Ansible | Альтернативные роли и новая местная песочница | Целевая ОС, порядок/права/восстановление перед реальным применением |
| Коммерция | Прайс 25/50/120 тыс. ₽, ограниченные часы, Gold gate | Фактические часы, CAC/retention, staffing, юрист/бухгалтер |

Код описывает механизмы, тест — выбранный сценарий, отчёт — прошлое применение. Книга не должна превращать их в неподтверждённое обещание действующей услуги.
