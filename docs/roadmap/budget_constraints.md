# Budget constraints

Жёсткий cap на расходы до появления MRR. Базовое ограничение из Q3:
«Личных денег максимально нет. Проект ради опыта, не могу дотировать
из семьи».

## Операционный бюджет до первого платящего клиента

| Статья | Cap | Комментарий |
|---|---:|---|
| Landing VM (Yandex Cloud) | 1 000 ₽/мес | `standard-v3` 2vCPU 2 GB, preemptible — 600-900 ₽ |
| Bastion VM | 400 ₽/мес | `standard-v3` 2vCPU 2 GB, preemptible — 300-600 ₽ |
| Домен + DNS | 1 000 ₽/год | 85 ₽/мес в среднем |
| SSL | 0 ₽ | Let's Encrypt |
| Kaiten | 0 ₽ | free tier до 10 user'ов |
| Vaultwarden | 0 ₽ | self-hosted |
| Почта | 0 ₽ | Яндекс.Почта для домена (free) |
| Telegram | 0 ₽ | — |
| Itog OPEX | **≤ 2 000 ₽/мес** | реальный таргет до первого клиента |
| CAPEX первых 3 мес | **≤ 5 000 ₽** | домен + резерв |

## Расходы НЕТ

- Платная реклама Яндекс.Директ / Google → **до M7**.
- Курсы по маркетингу → **нет**, self-learning.
- Агентства → **никогда** на этапе solo.
- SaaS CRM (Pipedrive, HubSpot) → Kaiten или Excel.
- Подписки (Notion, Linear, Miro paid) → только free tier.
- Наёмный копирайтер → пишем сами.
- Наёмный юрист → используем [`../../contracts/`](../../contracts/); при первой сложной сделке — один часовой разовый консалтинг (до 5 000 ₽).

## Расходы после MRR ≥ 50k

В порядке приоритета:
1. Backup отпуск (1-3 дня раз в квартал — «забываем про ноутбук»). **0 ₽**, но требует контракт с клиентами «автоответ P1 → R-02 inform client».
2. Первый монитор для супруги (если ведёт account mgmt активно). До **15 000 ₽**.
3. Подписка на Kaiten paid tier (если 10+ контактов). ≤ 1 000 ₽/мес.
4. Подписка на Яндекс.Почта для домена paid (если потребуется). 0-200 ₽/мес.

## После MRR ≥ 150k (найм Junior)

- Зарплата Junior: 70-90k/мес (см. [`../hiring/offer_and_ndca.md`](../hiring/offer_and_ndca.md)).
- Ноутбук Junior: 50-60k единоразово (б/у, из резерва).
- Обучение: до 20k/квартал, 50% от стоимости курса.

## Принцип

**Доллар вложен → доллар возвращается в 1 квартал.** Никаких инвестиций «на будущее», пока нет подтверждённой прибыли.

Если есть сомнение «тратить ли» — **не трати**. Возвращайся к этому файлу, смотри таблицу «Расходов НЕТ».
