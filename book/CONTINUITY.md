# Связность обучения

Цепочка владельца: ценность → зависимости → изменения → наблюдение → восстановление → ответственность → цена → продажа → передача. Цепочка маркетолога: проблема → узкий клиент → понятное предложение → разрешённый канал → подходящий разговор → оплата → измеримый результат.

Общая точка — обещание должно иметь механизм, владельца, ресурс и проверку. Каждый читатель объясняет свою часть другому. Непонятный технический термин превращается в вопрос, а не в рекламную гарантию.

Материалы в lessons редактируются человеком, chapters собираются. Отпечаток источника проверяет необходимость пересмотра главы, не автоматически обновляет смысл текста. После изменения прайса или схемы сервиса сборка без редакторской проверки недостаточна.
