# Регулярные проверки

| Период | Документ | Главное evidence |
|---|---|---|
| еженедельно | [`weekly.md`](weekly.md) | backup freshness, alert routes, open incidents |
| ежемесячно | [`monthly.md`](monthly.md) | restore sample, access review, client report |
| ежеквартально | [`quarterly.md`](quarterly.md) | clean-room DR, RTO/RPO, contract/scope review |

Чекбокс без ссылки на dashboard, ticket, snapshot или restore evidence не считается выполненным.
