# 3. Файлы, каталоги, пользователи и права

> **Учебная ситуация.** Restore-скрипт не видит архивы, хотя root видит их через `ls`.

Предыдущая глава: [глава 2](./02-исследование-незнакомой-системы-без-угадывания.md).

## Модель, которую нужно построить

Путь разрешается от root `/` либо текущего каталога. Каталог требует `x` для прохода; чтение файла не помогает, если нет прохода по родителю.

Mode `640` означает rw для владельца, r для группы и ничего для остальных. Для `.env` обычно нужен `600`, чтобы только владелец читал и менял файл.

Shell раскрывает `*` до запуска `sudo`. Если текущий пользователь не может прочитать каталог, root-команда получит буквальный шаблон или пустой список.

## Термины в рабочем смысле

### inode

Объект Linux filesystem с metadata и ссылками на blocks; имя находится в каталоге. Поэтому rename в пределах filesystem меняет directory entry, а не переписывает содержимое.

### permission

Проверяемое ядром право чтения, записи или выполнения для effective UID/GID процесса. `sudo` меняет identity команды, но не уже выполненное shell expansion.

### expansion

Преобразование shell до запуска программы: `$VAR`, `$(command)`, glob `*`, quotes. Ошибка expansion означает, что вызываемая программа могла вообще не увидеть ожидаемый аргумент.

## Что происходит внутри

При открытии `/a/b/file` kernel проверяет право прохода `x` на `/`, `/a`, `/a/b`, затем permission самого файла. Effective UID процесса определяется после `sudo`, но `*` раскрывает текущий shell раньше. Именно поэтому `sudo cat /root/x/file` работает, а `sudo cat /root/x/*` может вести себя иначе.

## Разобранный пример

```bash
namei -l /opt/msp-backups/current/volumes/data.tar.gz
stat -c '%U:%G %a %n' /opt/msp-backups/current/volumes/*
sudo sh -c 'cp /root/restore/*.tar.gz /tmp/migration/'
```

### Как читать пример

- `namei -l /opt/msp-backups/current/volumes/data.tar.gz` — Разделите строку на программу/оператор, options и operands; затем по документации установите side effect и exit semantics.
- `stat -c '%U:%G %a %n' /opt/msp-backups/current/volumes/*` — Разделите строку на программу/оператор, options и operands; затем по документации установите side effect и exit semantics.
- `sudo sh -c 'cp /root/restore/*.tar.gz /tmp/migration/'` — `sudo` запускает следующую программу с повышенной effective identity; shell уже обработал кавычки, glob и redirection.

## Практикум

1. Создайте root-only каталог и архив.
2. Воспроизведите ошибку `sudo cp /root/x/*.tar.gz /tmp/`.
3. Объясните, почему `sudo sh -c` меняет результат.

## Если результат не совпал с ожиданием

| Наблюдение | Что это означает | Следующая проверка |
|---|---|---|
| Permission denied | Это сужает область поиска, но не доказывает единственную причину | исследовать каждый компонент пути через `namei -l`. |
| Файл есть, glob не раскрылся | Это сужает область поиска, но не доказывает единственную причину | expansion выполнил пользовательский shell. |

## Самостоятельная работа

Решите изменённый вариант исходной ситуации: **Restore-скрипт не видит архивы, хотя root видит их через `ls`.** Измените один существенный параметр — host, port, credential, dataset, пакет или ограничение клиента — и сначала письменно предскажите результат. Затем выполните проверку на безопасном стенде. В отчёте оставьте исходное предположение, фактическое наблюдение, причину расхождения и способ восстановления.
